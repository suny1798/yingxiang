## 未覆盖与风险

- **Set-Cookie透传与API Range未在真实入口上复验**：真实入口不登录、不写库，故没有可返回`Set-Cookie`的真实登录响应，也没有可鉴权的真实作品媒体；这两项由 `npm run smoke:nginx` 在真实Nginx 1.28.3＋合成上游上覆盖（两条`Set-Cookie`、206／416／If-Range），不代表真实账务或媒体内容。
- **CSP差异**：旧Next只在 `/pricing`、`/account` 注入 `Content-Security-Policy`；Nginx模板未加CSP，静态入口当前无该响应头。这是既有模板的已知差异，需单独决定是否在入口层补CSP（不在本次切换范围）。
- **Windows版Nginx＋本机回环**：不代表Linux／HTTPS生产门槛；TLS、正式域名、进程托管／开机自启、日志轮转、限流与CDN策略均未做。当前入口只在回环，不对外公开。
- **单机单实例**：Nginx与FastAPI各一份，未验证多worker、重启恢复、并发压力与长连接超时；`proxy_read_timeout 130s` 只是空闲间隔，不是业务总截止。
- **预渲染边界**：未设置 `YINGXIANG_PUBLIC_ORIGIN`，因此没有canonical、`og:url` 与分享图绝对地址；英文仍为同URL客户端切换，抓取器只见中文默认meta；未验证真实搜索引擎收录。
- **数据与外部副作用**：未调用真实模型、真实Stripe、未登录真实账号、未写正式库；沙盒购买／管理写入的全部证据仍来自临时SQLite与替身（见M09-a／b）。
- **真实创作未验**：入口切换只证明静态资源、路由、代理与匿名边界；真实相机、真实供应商出画、真实付款仍需另批预算与账号。
- 8788 FastAPI 在切换前并未运行，本次按既有命令启动并保持；若机器重启，需按上文两条命令手动恢复入口与后端，尚无服务托管配置。
