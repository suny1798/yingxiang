# 衣装自动随机与账号收藏

用户2026-10-29新增；需求FR51／NFR06—09、T53，关联FR50／T52。状态以05为准。

- 设计：每次进入／刷新新建随机序列，保持四行初始及两行追加；上一次首套ID仅存本机sessionStorage，避免连续同首套。收藏使用本人账号，未登录点击收藏提示登录，详情收藏／取消，列表「我的收藏」和标签组合过滤。
- 实施：Vue独立收藏控制器隔离账号世代与迟到请求；Java Controller／Service／Mapper、V4增量表与公开ID清单，读写皆绑定本人及Owner头，写入精确Origin、严格布尔、幂等。收藏不混入私有作品，不复制图片，不占生成权益。
- 验证：单测随机序列、收藏确认／失败／身份变化；隔离PG schema与合成会话验证HTTP、账号隔离、幂等及持久化；浏览器刷新／重入随机、详情收藏、收藏筛选、刷新保留、取消、错误恢复与登录提示。
- 数据／回退：正式V4仅新增空表，先保存既有业务表指纹及备份再执行；不修改旧迁移，失败不回退旧SQLite。PG联合备份兼容V3／V4并包括收藏。Jar／API及Worker仍同版本，沿用既有配置和权限；不自动调用模型／支付、不公开发布。
