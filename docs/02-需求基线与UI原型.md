## 1. 需求基线

**品牌与定位**：映想；让想象，在眼前发生。整体定位为实时画面创作，已接入实时换装、视频换装和提示词实时编辑。具体扩展对象仍按实际开发与验证范围描述，不将示例或概念图视为效果承诺。

**首个场景目标**：让受邀用户通过服装图和摄像头，在浏览器连续视频中观察单人画面中的生成换装效果。本文 FR/NFR 与线框继续约束该首版场景，后续扩展单独做需求和可行性验证。

**首版用户**：普通体验用户；运营人员使用受保护的内部方式管理邀请、预算和指标。商家演示沿用体验流程，不增加专用工作台。

**首版闭环**：受邀访问 → 选择服装图片 → 阅读处理说明并主动开始 → 摄像头授权 → 业务授权与实时连接 → 试穿/换衣/对比 → 主动或自动结束。

**首版范围**：设计主文档第2—3章的 P0；FR12 截图为 P1。受邀身份必须存在；后续版本的“登录”指完整账号体系，不能误解为首版没有鉴权。

**需求唯一依据**：FR01—FR12、NFR01—NFR09 的完整条款在[设计主文档](../实时虚拟试衣网页项目设计文档.md)。本文件补充交互，不重编需求编号或另设性能门槛。

## 6. 状态与操作规则

身份/额度状态与媒体状态分别维护，不能把“已登录”或“已分配会话”当作模型已连接。

| 状态 | 用户看到的内容 | 可用操作与退出方式 |
| --- | --- | --- |
| 邀请未兑换/失效 | 输入入口或失效说明 | 兑换邀请码；不申请相机、不签模型令牌 |
| idle | 上传指引与开始前说明 | 选择图片；开始按钮禁用并说明原因 |
| 图片处理中 | 正在检查图片 | 可取消；不能开始；旧有效图片保持可用 |
| imageReady | 有效预览与试穿说明 | 替换图片；完成告知后开始 |
| requestingCamera | 浏览器授权引导 | 可取消；迟到相机流必须停止；不签付费令牌 |
| creatingSession | 正在检查体验资格 | 可取消；额度/容量/系统停用失败时关闭相机并提示 |
| connecting | 正在连接试衣服务 | 可结束；禁止重复开始；不能显示为“试穿中” |
| live | AI画面、有效剩余时间 | 换衣、原画对比、切相机、结束 |
| updatingGarment | 正在应用新服装，保留原图预览 | 可继续选图，仅保留最新待发送项；可结束 |
| reconnecting | 连接中断，正在恢复 | 可结束；倒计时继续；原画必须标识，不能冒充生成结果 |
| stopping | 正在结束 | 阻止新连接与更新，重复结束幂等 |
| ended | 已结束及原因 | 有效图片可保留在本地供再次开始；无活动相机/模型流 |
| error | 可理解的错误与恢复建议 | 清理后重试或换图；不得自动循环新建付费会话 |
| 额度不足/容量满/停用 | 分别显示稍后再试、额度耗尽或服务暂停 | 不提供无限重试；遵守 Retry-After |

页面进入后台时结束会话。打开系统文件选择器、权限面板等交互在目标浏览器上需实测其可见性事件；如触发后台结束，应在回到页面后说明原因，不能静默恢复生成。

服装更新 API 返回仅代表提交完成。首版无可靠的自动服装识别事件时，文案使用“新图片已提交，画面正在更新”，不自动显示“换装成功”；真实换衣耗时通过评估人工标注。

## 7. 视觉与可操作性要求

- 以画面为核心，背景保持中性，主操作使用单一强调色；最终颜色、字号和间距在可交互原型阶段确定。
- 开始与结束位置稳定，结束在连接、播放及重连时均可触达；结束不增加二次确认弹窗。
- 按钮有焦点与禁用说明；错误同时使用文字，不能只改变颜色。
- 状态更新可被辅助技术读取，避免每秒倒计时重复播报干扰操作。
- 使用键盘可以完成选图、开始、结束与对比；视频加载和空白区有语义说明。
- 操作区不堆叠供应商、SDK 或 WebRTC 术语；用户需要理解的是授权、等待、恢复和结束。

## 8. 原型验收走查

S2 已产出第一版可交互原型，使用明确标识的原创占位插画，不开启相机、不调用付费 API。以下保留为持续走查清单。

1. 未选图能否理解下一步；错误图是否保留旧图？
2. 开始前能否理解视频将由云端处理；不勾选是否无法开始？
3. 授权等待、连接与重连是否能取消；结束按钮是否始终可用？
4. 原画与生成画面是否易于区分；换衣是否避免假成功？
5. 额度不足、容量满、断网和时限到期后能否找到恢复方式？
6. 窄屏及键盘操作是否可完成主流程？

浏览器交互及布局检查记录见视觉设计方案第6节；完整键盘/读屏走查、真实用户反馈和最终设计审核尚未完成。原型通过基础检查不等于 S2 已最终通过。

## 13. 创作空间精简与原画上的悬浮换装

2026-10-23用户要求减少文字并解耦相机与生成。当前/studio去除大标题、宣传段落、权益横条、示意人台、左侧长说明与重复引导，只保留简短工作区标题、服装参考图、画面/视图切换、相机操作和隐私入口。空态是相机图标，不冒充生成结果。
