# M10-a Java启动底座验收记录

日期：2026-10-27。关联[任务卡](../migration/tasks/M10-a-Java启动底座.md)、M10及NFR06—09、FR09／10，覆盖T51-C01／C03／C11／C12中与离线启动、错误边界有关的部分。任务最终状态以[05](../05-开发任务与验收.md)为准。

## 范围与实现

用户明确先启动Java，再用Maven依赖验证云PG／Redis；本轮提前执行M10的无数据库依赖子片。Java工程直接位于原backend，新增pom、官方Wrapper、src/main、src/test与Jar验收脚本；Python工程和现有前端继续保留，应用入口和数据库未切换。

默认offline，仅回环127.0.0.1:8792。未读取本机.env／.env.migration.local，不创建DataSource或RedisClient，不运行DDL／Flyway、不访问供应商。JDBC与Lettuce仅作为后续Java连接检查的驱动依赖，此轮没有发送云凭据或再次探测SSH。

自定义关闭边界覆盖全部请求：/internal/live返回200，/internal/ready返回503并明确BUSINESS_MIGRATION_PENDING。由冻结OpenAPI导出的44个路径／48个操作一律503 SERVICE_DISABLED；未知404、方法不支持405、OPTIONS204，HEAD无正文。错误使用error／requestId包络，响应no-store／nosniff，不发登录Cookie、Basic挑战或跳转。

本轮没有接Spring Security身份协议。精确Host／Origin与Sec-Fetch-Site检查、拒绝不安全配置及关闭全部业务构成M10-a的临时边界；后续身份迁移必须显式替换，不能据此认定认证或授权已迁移。来源校验使用未来入口http://127.0.0.1:8791；直连Jar须带相应Host，详见backend/README。

Boot精确版本写入pom，传递依赖由该版本BOM固定；上述运行依赖已从最终Jar的BOOT-INF/lib核对。Wrapper发行包来自Maven Central，SHA256为 `0d7125e8c91097b36edb990ea5934e6c68b4440eef4ea96510a0f6815e7eeadb`，已写入wrapper properties。

本机原Maven使用安装目录的settings.xml及现有镜像／缓存，Wrapper不会自动继承安装目录配置。首次默认Wrapper下载较慢后中止，随后显式复用本机已有settings完成构建；没有改全局配置，也没有把本机镜像／凭据写入项目。

```powershell
# backend/，本机实际成功命令
.\mvnw.cmd -s D:\Code\Tools\apache-maven-3.9.11\conf\settings.xml -B -ntp verify
.venv/Scripts/python.exe -m scripts.java_offline_smoke
```
