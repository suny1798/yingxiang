# 映想 UI 视觉设计方案 V1

日期：2026-10-22；状态：本地可交互原型已制作并走查，等待用户审核。不是正式应用或模型效果验证。

本文件的“未提交”内容为原型阶段的历史记录。用户现已授权验证后自行本地提交，当前规则以 AGENTS.md 和开发流程第7节为准；视觉审核与 Git 提交分别处理。

## 1. 视觉方向

用户要求：简约、有个性、浅色，不使用常见技术产品的蓝色主视觉。

项目正式名称为「映想」，品牌标语为「让想象，在眼前发生。」。整体定位为实时画面创作，首个体验场景为实时换装；提示词创作、室内背景、宠物与摆件等方向仍在规划中。

本版采用“浅色创作空间”：雾白页面、暖灰画面区、炭灰文字、少量莓果红交互。品牌用中文宋体字标，主标题展示完整标语。当前换装场景继续使用拱形预览区和裁衣人台插画，其余区域保持克制，便于以后扩展其他场景。

原先线框的上传与视频两区结构保留；将视觉重心进一步放到试衣镜，去除不必要的信息卡片。未增加商城、云端衣橱、下载、付费或实际模型接入。

## 2. 网上参考与使用方式

- [Drop Edition 官网](https://dropedition.com/)：实际查看了白色导航、服装主视觉与克制的页面层次，借鉴其把服装放在中心的展示思路。
- [Square43 的 Drop Edition 设计案例](https://square43.com/drop-edition)：设计方将其描述为强调服装、层次与浏览节奏的视觉系统；用于理解设计意图。

参考访问日期：2026-10-22。当前界面是针对试衣工具重新设计，没有复制参考站的页面源码、品牌或服装摄影。全部插画和图标是项目内的 SVG，无外部图片或字体依赖。

参考服装站点与实时试衣工具的任务不同，因此没有照搬全屏宣传首页、商城导航或购物流程。

## 3. 设计令牌

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 雾白 | `#F8F7F4` | 页面背景 |
| 纸白 | `#FFFEFA` | 上传区及试衣面板 |
| 炭灰 | `#292622` | 主要文字 |
| 暖灰 | `#756F69` | 次要说明 |
| 莓果红 | `#793D50` | 开始按钮、选中状态、链接与焦点 |
| 浅莓粉 | `#F0E3E6` | 轻提示与结束按钮底色 |

分隔线 `#E5E1DC`，试衣舞台 `#EEEBE6`。苔绿仅用于状态点和示意服装，不成为第二套品牌主色。纯白与炭灰的色差用于内容层级，避免大量阴影和渐变装饰。

「映想」字标使用 Songti SC / STSong / SimSun 等本地宋体；正文使用 PingFang SC / Microsoft YaHei 等本地无衬线字体。标题约30—42px，功能标题13—17px，主要操作与确认文案11—13px，辅助注释更小。最终字号可依据审核和实际设备继续调整。

桌面最大内容宽度1280px，上传栏310px，主区自适应，间距22px；面板18px圆角，内部画面10px圆角。手机改为单列，开始演示后滚动到试衣区，结束按钮固定在可触达位置。

## 4. 页面与交互

| 区域 | 当前原型能力 |
| --- | --- |
| 顶部导航 | 创作空间、体验指南、受邀体验示意弹窗 |
| 图片输入 | 文件选择与拖放、本地处理及预览、替换、移除、格式错误与旧图保留 |
| 示意服装 | 云白衬衫、莓果针织、苔绿外套；仅用于走查原型，不自动将 P1 示例服装加入正式首版范围 |
| 开始前说明 | 未选服装或未确认处理说明时禁用开始；提供数据处理说明弹窗 |
| 画面预览 | 准备、资格检查、连接、画面体验、换图、重连、错误、结束等示意状态 |
| 画面控制 | 映想画面/原始画面标签切换、倒计时、结束体验与再次开启 |
| 预览工具栏 | 权限拒绝、容量满、额度耗尽、连接失败、网络中断和重置 |

倒计时和错误均由本地逻辑演示，不是账户、API 或网络实测。人台插画保持静态，上传服装不会改变人物或生成视频；标签和底部工具栏持续明确其示意性质。原型未实现真实相机选择、模型接入或运营后台。

当前不访问相机、不采集音频、不发送图片、不使用 localStorage；上传图片只在页面内处理与预览，替换/离开后释放相关引用。正式数据处理文案仍需根据最终供应商条款收敛。

## 6. 本轮验证记录

运行环境：本机 Playwright 控制的 Chromium；未进行手机实机或 Safari 验证。

- 320、390、768、1024、1440px 布局均检查无横向溢出；保存桌面与手机截图并目视检查。
- 正常流程、未选图/未确认时的禁用、换衣、原画标签切换、结束与再次开始通过。
- 准备中立即取消后，迟到状态未重新启动；快速选择服装保留最后一件。
- 4种错误预览、邀请码错误/有效交互、指南弹窗及 Escape 关闭通过。
- PNG 本地预览、伪装 JPEG 拒绝、GIF 拒绝及无效图片保留旧图通过。
- 手机准备阶段结束按钮位于视口内；模拟重连后倒计时未重置；重置原型通过。
- 页面资源均来自本机；当前页面控制台无错误；JS语法与3个SVG的XML解析通过。
- 主要文字/雾白背景、次要文字/纸白背景、白字/莓果按钮对比度分别约14.06、4.91、8.09；这不是完整无障碍认证。

本次修复了走查中发现的示意服装预览选择器错误，并重新验证。尚未认证完整文件安全限制、相机权限、真实换装效果、供应商停止与计费、完整键盘/读屏可用性；正式验收仍按 S5 执行。
