# 映想

**让想象，在眼前发生。**

映想是一款面向实时画面创作的网页产品，规划通过提示词改变视频中的穿着、室内背景、宠物与摆件等内容。首个实现与验证场景为实时换装：选择上衣参考图、主动开启相机、观察生成画面并与原画对比。提示词及其他场景仍属于后续规划，尚未实现或完成模型验证。

当前已进入工程开发：Next.js + React + TypeScript 应用位于 `frontend/`，界面沿用雾白、暖灰与莓果红。普通工作区提供本地图片处理、主动开启的真实摄像头预览及可取消的Mock。独立`/poc`已完成一次Decart真实出画，用户确认上衣有明显变化且基本符合参考图；完整模型评估、正式业务、数据库/Redis和公开部署仍未完成。真实相机支持范围仍以设备验收记录为准。

UI 审核可先打开 [本地预览](http://127.0.0.1:8765/prototypes/ui-v1/)；服务未运行时按 [原型运行说明](prototypes/ui-v1/README.md) 启动。原型不使用摄像头或模型。

## 启动应用

使用 Node.js 22+，从项目根目录进入前端工程后执行：

```powershell
cd frontend
npm ci
npm run dev
```

打开 [映想应用](http://127.0.0.1:8787/)。默认绑定本机127.0.0.1:8787（本机3000端口不可用），不能通过双击HTML运行正式应用。选择参考图并确认当前本地处理说明后，点击“开启映想”申请相机权限；只采集视频，在本地显示镜像原画并保持完整比例。AI画面仍为Mock示意。没有相机或不希望授权时，可选择“仅模拟流程”。切换模式会结束体验，并要求重新确认处理说明。

结束、移除参考图、取消处理确认、切后台或离开页面会停止相机；等待授权时也可结束，迟到返回的流会关闭。普通工作区不上传图片或视频，不录制、不采集音频；独立PoC的云端路径见下节。摄像头需要浏览器支持及本机地址或HTTPS；部署到普通HTTP局域网地址不代表相机可用。工具栏可以模拟错误和连接恢复。

```powershell
npm run typecheck
npm test
npm run build
npm start
```

以上命令均在 `frontend/` 中执行。服务启动后可在另一终端进入 `frontend/`，运行 `npm run smoke`，检查页面、生产资源、API模式与真实接口关闭状态。停止本地服务使用运行终端的Ctrl+C。

`npm run check`依次执行类型检查、逻辑测试与生产构建。提交锁文件，使用npm ci复现依赖。配置示例见 [frontend/.env.example](frontend/.env.example)，本地环境文件也放在 `frontend/`。普通工作区仍是本地预览与Mock；真实模型仅在明确启用的独立本机PoC入口调用。

GET /api/v1/config 和 /api/v1/health 可用；真实会话、令牌及邀请接口明确返回503 SERVICE_DISABLED。详细边界见 [接口契约与工程实现](docs/07-接口契约与工程实现.md)。

## 首次真实模型验证

用户已于2026-10-23批准最多5美元，先执行一次短时测试。已安装固定版本Decart SDK 0.2.12，并提供[独立本机测试页](http://127.0.0.1:8787/poc)；密钥只在frontend/.env.local。须同时开启YINGXIANG_POC_ENABLED，并在页面中重新确认参考图及视频将发送至Decart云端；仅填写密钥不会使普通工作区变为真实模式。

本轮标准档VTON 3.6、15秒单连接上限、一次令牌签发；关闭初次重试及可选遥测，失败后先核对用量。此为本机PoC，不提供公开登录、跨实例配额或已验证的账单硬限制。操作及限制见[首次真实模型测试操作](docs/09-首次真实模型测试操作.md)。

2026-10-23首批连接失败；用户另行批准的diagnosis-02已真实出画，首个远端播放观测3985ms、供应商事件秒数5、结束时本地轨道已关闭。用户确认上衣基本符合参考图、控制台已有用量，但具体金额/计费秒数尚待补充；事件秒数不是账单。两批均已用完并保持锁定，费用仍受原5美元总授权约束，不自动创建第三批。详情见[真实模型接入验证](docs/reports/2026-10-23-真实模型接入验证.md)。

## 当前推进顺序

1. 按需求基线推进，记录目标地区、设备与预算等待确认的事项。
2. 在无密钥条件下细化交互原型、Mock 场景和评估样本清单；原型不得显示虚构的真实试穿结果。
3. 有模型账户和明确测试预算后执行限额 PoC，记录实际网络、效果、时延和账单。
4. 依据 PoC 收敛技术设计，再逐个完成开发任务与验收。

项目设计使用 Markdown 维护，正式应用使用TypeScript；Word文件不作为后续执行入口。prototypes/ui-v1保留为设计参考，运行应用以 `frontend/` 和其中的npm脚本为准。

Git 已初始化。按当前协作约定，完成改动与验证后先展示结果，用户明确审核同意后再创建本地提交，采用 `feat/fix/docs` 等类型，不自动推送或公开发布。
