# M09-b：Vue管理与公告

前置M04-a3无权管理门禁与M09-a通过；当前状态只在05维护。关联FR43—45、T51-C01/C02/C04，按16附录A.1／A.3实施。沿用当前worktree/frontend，正式入口不切换。

## 输入与行为切片

`/admin`在原匿名／普通用户门禁之后补齐原管理控制台，DOM、CSS类、文案和键盘保持原实现：项目总览、用户与权益、实时使用记录、视频任务、沙盒订单、服务与内容、操作日志七个标签，一次只读取当前标签。

- 总览：注册用户／视频任务／实时申请／结果待核查、服务运行边界表（配置、后台暂停、预留／预算、申请数／上限）、账号与支付（可用管理员、暂停账号、沙盒订单、Stripe沙盒与正式支付状态）。
- 用户与权益：账号搜索与分页；账号编辑器可改角色／暂停（说明会撤销旧会话、不能操作自己、至少保留一名管理员）并按15／30／60秒增减可用体验次数，不能修改已用或预留次数。
- 记录：实时申请、视频任务、沙盒订单按关键词与状态查询；只读业务元数据，不加载媒体、不修改结果或金额。
- 服务与内容：服务暂停开关（在现有配置之上，不启用原本关闭的功能、不改预算、不取消在途任务）；站点公告（纯文本、中英正文、可关闭）；页面与商品内容说明与三个站内链接。
- 操作日志：操作、时间、操作者、对象、原因与修改前后值；网页不可删除或改写。

写入统一经确认弹窗：先“核对…”生成摘要，再“确认保存”才POST；同一修改复用操作编号，失败不自动重试；版本冲突保留待确认并显示服务器提示；401／403立即隐藏管理数据并刷新本人权限。公告与暂停状态由真实管理写入持久化，全站公告读取 `/api/site/announcement`，创作入口的服务可用性读取后端暂停状态。

不新增API、数据库迁移或权益规则；不触碰正式库与真实管理员账号。

## 验收

- 单测覆盖：确认前不写入、确认后单次POST带操作编号、写入中重复点击不重发；失败保留待确认并复用同一编号、修改内容后另建编号；401／403立即隐藏数据并停止待确认；卸载中止在途写入且迟到结果不更新；标签切换与刷新受写入中状态保护。
- 浏览器在1440×1000桌面，使用临时SQLite、合成管理员（经仅临时库可用的身份控制提升／撤权）：匿名与普通用户门禁、总览、用户搜索、权益写入与确认、真实暂停后视频创作入口不可用、公告发布／全站显示／关闭、审计原因与前后值、撤权后写入403并立即隐藏数据。
- 全部旧路由与404在Vue入口可用；`npm run smoke`扩展为20条路由。
- 既有七个桌面脚本回归；`npm run check`、`npm run legacy:typecheck`通过。

## 边界

- 管理写入只在临时SQLite与合成账号上验证；未使用正式管理员账号、正式数据库或正式公告内容。
- 版本冲突在浏览器用明确409替身触发（后端冲突逻辑由既有后端测试覆盖），不宣称并发冲突已在浏览器实测。
- 撤权写入测试期间冻结本人账号读取，避免十秒轮询提前把控制台替换成门禁；写入请求本身是真实403。
- 实时换装页的暂停提示需要相机就绪才显示，浏览器未观测；暂停对创作入口的影响以真实管理写入、总览暂停列与视频换装入口状态验证。
- 私有页面的服务端robots／meta仍由SPA壳承担，客户端标题不等价于服务端meta；入口切换前须按16附录A.2补齐或确认。
- 不切正式入口、不push；入口切换须用户明确授权。
