# M13-b：角色、权益、公告与审计

父片M13，关联FR35／43—45、NFR06—09及T51-C03／04。依赖M11会话与M12账本；Vue入口与正式切流未迁移。

本轮功能：迁移旧运营台的本人会话管理员鉴权、概览、用户分页搜索、角色／停用变更、权益增减、记录分页筛选、设置版本冲突、公告启停与审计。所有写操作要求有效管理员、精确来源、UUID操作编号和至少3字原因；同编号同输入幂等返回accepted，同编号不同输入409；自锁与最后管理员保护；停用或角色变更删除该账号会话；权益只回收未使用、未预留部分并写revoke流水；服务暂停与公告使用版本号乐观锁；公告公开读取不返回停用正文。

实现方式：Spring JDBC＋真实PostgreSQL短事务（REQUIRES_NEW，READ COMMITTED，10秒），行锁＋唯一约束；审计`changes`保存规范化input与before／after，供重放比较与人工核查。角色、权益、设置变更与审计同事务提交。

验收：同一临时schema与合成Stripe替身；覆盖匿名401、非管理员403、来源错误403、概览计数与服务状态、用户分页与时长权益、角色提升并撤销会话、重放幂等、冲突409、自锁409、权益增减／过度回收／零调整、设置版本冲突、公告公开与隐藏、审计字段与分页、记录筛选与非法类型、维护模式只读可用、重启后审计与设置持久。证据同上片报告。

边界：不真实改正式账号、不发放真实模型权益；概览的scene预算／请求上限在M14／M16接入前为null；不替代M21导入核对。
