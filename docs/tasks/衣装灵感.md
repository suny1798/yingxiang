# 衣装灵感：素材筛选至创作空间

来源：用户2026-10-29要求。状态与验证统一见[05](../05-开发任务与验收.md)。关联主文档FR50／NFR09、T52，兼容FR27、FR34、T28／35。

- Brainstorm：966张衣装图及源中英标签可直接使用；不需要新模型、后端或数据库能力。
- Design：顶部「衣装灵感」→四季混排画廊；左侧季节和全部标签可多选，季节取并集、标签取交集；搜索、清空、滚动追加（初始四行，每次追加两行）、空态、预览；随机一组按当前筛选四行换组并保持后续追加不重复，选择保留；完整图像不裁切。底部选衣条最多6套，单套也可直接去换装。
- Plan／Execute：本机源PNG生成两档WebP；清单引用受控ID，URL只携带最多6个有效素材ID；创作页下载本站静态参考图并复用既有图像校验和衣橱；主动开启相机、云端同意、登录及开始规则沿用原链路。
- Verify：逻辑测试覆盖组合筛选／选图边界／非法ID／加载失败与取消；桌面浏览器检查三／四／五列下四行初始、滚动两行追加、条件变化重置、末尾停止、画廊、预览、选择跨筛选保留、导入、暗色／英文、异常及无自动生成；类型／构建及入口回归。
- Ship：本机8787构建更新，按功能本地提交；不push、不公开发布、不执行真实模型调用。原文件不改写，非素材私有目录不读取。
