# 映想业务外部接口清单

- 日期：2026-10-26
- 范围：实时换装、视频换装、实时编辑、支付、本地媒体处理
- 性质：**代码事实梳理**，只记录当前使用的接口、类型、端点、调用方和约束
- 说明：上游服务的实际媒体节点、端口和可用性以运行时连接为准；本文不代表生产验收或上线批准

## 1. 接口类型总览

当前业务同时使用 **Realtime** 和 **Process/Queue** 两种形态。

| 能力 | 上游 / 模型 | 接口类型 | 调用方 → 上游 | 实现状态 |
| --- | --- | --- | --- | --- |
| 实时换装 | Decart Lucy VTON 3.6 | **Realtime**：WebRTC 媒体 + WSS 信令 | 浏览器 → Decart | 代码已接入；受服务端开关、密钥、预算与权益限制 |
| 实时编辑 | Decart Lucy 2.5 | **Realtime**：WebRTC 媒体 + WSS 信令 | 浏览器 → Decart | 代码已接入实时通道；受测试账号、开关、预算与效果验收限制 |
| 视频换装 | Decart Lucy VTON 3.6 Batch | **Process/Queue**：异步 REST 作业 | 浏览器 → 本地 BFF → Decart | 代码已接入；受测试账号、预算和任务门禁限制 |
| 图片生成 | 无独立外部图片 API | 不适用 | 浏览器本地处理 | 服装图在浏览器本地处理后作为参考图发送给 Decart |
| 支付 | Stripe | REST + 托管 Checkout + Webhook | 后端 → Stripe；浏览器 → Checkout；Stripe → BFF | 仅测试模式 |

## 2. 调用关系（事实）

```text
实时换装 / 实时编辑
  浏览器 ── WSS 信令 + WebRTC 媒体 ──▶ Decart（LiveKit）
      │
      └── HTTPS ──▶ 本地 BFF：状态 / 短期 token / 观测

视频换装
  浏览器 ── HTTPS ──▶ 本地 BFF ── HTTPS/multipart ──▶ Decart Batch API
      ▲                         │
      └──── 轮询 / 下载 ◀──────┘

支付
  后端 ── HTTPS ──▶ Stripe API
  浏览器 ── 跳转 ──▶ checkout.stripe.com
  Stripe ── Webhook ──▶ BFF /api/payments/webhook
```

- 实时换装/实时编辑：媒体流由浏览器直接连 Decart，不经过 BFF；BFF 只签发短期 token、返回状态和记录观测。
- 视频换装：Decart 的提交、状态查询、结果下载都由 BFF 发起；浏览器只访问 BFF。
- 支付：后端调用 Stripe API；浏览器跳转 Stripe 托管页；Stripe 通过 Webhook 回调 BFF。

## 3. 外部接口明细

### 3.1 实时换装

| 项目 | 内容 |
| --- | --- |
| 供应商 | Decart |
| 模型 | `lucy-vton-3.6` |
| 浏览器 SDK | `@decartai/sdk@0.2.12` |
| 媒体 | 摄像头视频 + 服装参考图 |
| 实时连接 | WebRTC 媒体（LiveKit）+ WSS 信令 |
| 默认 API 地址 | `https://api.decart.ai` |
| 默认实时地址 | `wss://api.decart.ai` |
| token 接口 | `POST https://api.decart.ai/v1/client/tokens` |
| token 请求头 | `X-API-KEY`（服务端长期密钥） |
| token 响应字段 | `apiKey`（短期客户端 token）、`expiresAt` |
| token 约束 | TTL 10 秒；限定模型、页面 Origin、`constraints.realtime.maxSessionDuration` |
| 单次时长 | 15 / 30 / 60 秒（以 token 约束为准） |
| 本地 BFF | `/api/studio/status`、`/api/studio/token`、`/api/studio/observation` |

补充事实：

- 长期 `DECART_API_KEY` 只在服务端使用；浏览器只拿短期客户端 token。
- SDK 支持覆盖 `baseUrl`、`realtimeBaseUrl`，也支持 `proxy` 模式；当前代码未设置这些覆盖项。
- 实际 LiveKit 媒体域名、ICE/TURN 路径和端口由 SDK 与供应商连接过程决定，代码中没有写死。

### 3.2 实时编辑

| 项目 | 内容 |
| --- | --- |
| 供应商 | Decart |
| 模型 | `lucy-2.5` |
| 连接类型 | WebRTC + WSS，与实时换装同类 |
| 单次时长 | 15 秒 |
| 输入 | 相机画面 + 提示词状态；不上传服装参考图 |
| 本地 BFF | `/api/prompt/status`、`/api/prompt/token` |
| 当前限制 | 代码已接实时通道；受测试账号、开关、预算与真实效果验收限制 |

提示词正文由浏览器直接发给 Decart；BFF 不保存提示词正文，也不转发实时媒体。

### 3.3 视频换装

| 项目 | 内容 |
| --- | --- |
| 供应商 | Decart |
| 模型 | `lucy-vton-3.6` |
| 接口形态 | 异步 REST 作业（Process/Queue） |
| 提交 | `POST https://api.decart.ai/v1/jobs/lucy-vton-3.6` |
| 提交格式 | `multipart/form-data` |
| 提交字段 | `data` 人物视频、`reference_image` 服装图、`prompt`、`resolution`、`enhance_prompt` |
| 鉴权 | `X-API-KEY`（服务端长期密钥） |
| 提交结果 | `job_id`、`status`（`pending` / `processing` / `completed` / `failed`） |
| 状态查询 | `GET https://api.decart.ai/v1/jobs/{job_id}` |
| 结果下载 | `GET https://api.decart.ai/v1/jobs/{job_id}/content` |
| 分辨率 | `720p` |
| 输入限制 | MP4、1—15 秒、≤25MB；应用侧先移除音轨 |
| 输出限制 | 上游结果约 200MB 上限；应用侧访问窗口 24 小时 |
| 轮询 | 前端可见时约每 4 秒查 BFF；后端对上游至少间隔 3 秒 |
| 超时 | 提交 60 秒、状态 15 秒、下载 120 秒 |
| 本地 BFF | `/api/video/prepare`、`POST /api/video/jobs`、`GET /api/video/jobs`、`GET /api/video/jobs/{id}`、`GET /api/video/jobs/{id}/content`、`/api/video/history` |

补充事实：

- 接口类型是异步作业队列，但实现为直接 REST job API，未使用 SDK 的 Process/Queue 封装。
- 浏览器不直接访问 Decart；结果内容由 BFF 流式转发给浏览器。

### 3.4 支付

| 项目 | 内容 |
| --- | --- |
| 供应商 | Stripe |
| 形态 | 同步 REST + 浏览器跳转托管 Checkout + 入站 Webhook |
| 服务端 API | `api.stripe.com`（Checkout Session 创建/查询） |
| 浏览器跳转 | `checkout.stripe.com` |
| Webhook | `POST /api/payments/webhook`，需要签名校验 |
| 本地 BFF | `/api/payments/status`、`/api/payments/orders`、`/api/payments/checkout`、`/api/payments/reconcile`、`/api/payments/webhook` |
| 当前状态 | 测试模式；正式支付、退款与争议处理未完成 |

### 3.5 不涉及外部 API 的部分

- 服装图片读取、压缩、尺寸检查、缩略图：浏览器本地。
- 相机采集、镜像、Canvas 合成、MediaRecorder 录制：浏览器本地。
- 视频音轨移除、MP4 容器处理：本地 FastAPI。
- 账号、权益、作品、历史、积分、沙盒订单：本地 FastAPI + SQLite。
- 没有独立的第三方图片生成、对象存储或 CDN 上传接口。
