# M05-a3：本机视频选片、校验与预览

比较点0b0825b；关联FR02/03/27/29/47/48、T51-C06/C07与[M05-a任务卡](../migration/tasks/M05-a-Vue本机媒体与画面工具.md)。本片迁移视频换装页的本机部分：选片、MP4校验、时长／音轨识别、静音预览、镜像／全屏／PNG与离开清理；不提交任务、不上传、不调用模型。

## 实现

/studio/video接入Vue页面，沿用原VideoStudio、inputs／output、empty、wardrobe等DOM／文案／CSS与三模式导航；`StudioModes`抽为React与Vue共用的单一导航组件，/studio同步改用，DOM与`aria-current`不变。App仅在视频页设置`data-mode=video`，不改变原realtime页面。

视频校验复用`inspectVideo(bytes,{allowAudio:true})`，只读本机文件字节：大小／扩展名不合格直接拒绝，格式、时长、轨道结构按原规则报错；`LocalVideoFile`持有文件、对象URL、时长与音轨标记，替换、移除、隐藏、站内离开、换账号或卸载都推进操作号并释放URL，迟到读取与迟到URL不进入页面。已认证身份变化清空视频与参考图，访客登录保留仍有效的本机素材。

检测到音轨时只显示“本机预览为静音，云端提交时会自动移除”，不调用`/api/video/prepare`、不声称已在本地去音轨；预览`muted`，与后续云端处理边界一致。参考图复用`GarmentInput`（6张上限、批次解码、失败保留原列表），错误只在本页显示。

画面工具复用a2的`LocalFrameTools`，本页默认镜像关闭（与原视频页一致），全屏目标为视频画框，PNG按点击时镜像导出“映想-本地人物视频-时间.png”；下载、换装结果与提交入口保持不可用，底部明确显示“本地预览 · 不上传／换装服务暂未就绪”。视频提交、unknown与结果收取仍归M08-a。

## 实际验证

完整`npm run check`通过：OpenAPI类型、Vue类型、169项测试（a2的161项＋8项本机视频与镜像编排）、Vite构建；`legacy:typecheck`通过；`npm run smoke`通过17条静态路由（新增/studio/video）与SDK非空检查。

Playwright CLI在1440×1000与1280×900桌面执行`scripts/browser/local-video-studio-check.js`通过：空态与工具／结果／下载禁用；损坏MP4、非MP4与超过25MB文件在本机拒绝且不创建URL；延迟读取时取消与切后台都不产生视频；有效示例MP4识别为7.7秒并显示文件名、时长与音轨说明，预览为静音blob URL。

加载后可截图：PNG为1280×720、`image/png`，文件名为`映想-本地人物视频-<ISO时间>.png`；默认镜像关闭，开启镜像后同一视频URL不变，逐像素核对镜像PNG与未镜像PNG为水平翻转。全屏进入／退出目标为当前画框；英文／暗色下工具、音轨说明与状态文案翻译正确。

移除视频与站内离开都会撤销本机URL，返回不新建视频；运行时异常0、MediaRecorder实例0、`/api/video*`及其他业务POST 0，无SDK／LiveKit预热或视频接口读取。a1／a2桌面脚本在同一构建上回归通过。

示例MP4为本地用户素材，只复制到`frontend/output/playwright/fixtures/`忽略目录，不提交；截图含人物画面，核对后删除、未保留。测试不代表真实摄像头、真实音轨移除、真实生成效果或供应商可用性。

Spec／Standards为同Agent自检，非独立Review。按功能本地提交，不push、不切流。M05本机媒体与画面工具范围完成；M06作品管理、M07实时换装、M08视频提交／实时编辑、M09入口与G1仍独立验收。
