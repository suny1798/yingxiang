# 映想

**让想象，在眼前发生。**

映想是一款面向实时画面创作的网页产品，规划通过提示词改变视频中的穿着、室内背景、宠物与摆件等内容。首个实现与验证场景为实时换装：选择上衣参考图、主动开启相机、观察生成画面并与原画对比。提示词及其他场景仍属于后续规划，尚未实现或完成模型验证。

Next.js + React + TypeScript 应用位于 `frontend/`，界面沿用雾白、暖灰与莓果红。创作空间已接入Decart实时换装，旧模拟/测试入口及旧PoC页面/API已移除；本地相机现可独立预览，再通过原画上的悬浮卡开启真实换装。现已增加本机账号模块：用户名密码注册/登录，每账号一次免费体验、最多15秒，不自动重连；先前不限手动次数的运行入口已收紧为账号权益检查。此前独立`/poc`已完成一次真实出画；主页迁移本轮只做无费用回归，完整模型评估、短信、支付、正式数据库/Redis、生产配额及公开部署仍未完成。

UI 审核可先打开 [本地预览](http://127.0.0.1:8765/prototypes/ui-v1/)；服务未运行时按 [原型运行说明](prototypes/ui-v1/README.md) 启动。原型不使用摄像头或模型。

## 启动应用

使用 Node.js 22+，从项目根目录进入前端工程后执行：

```powershell
cd frontend
npm ci
npm run dev
```

打开 [映想首页](http://127.0.0.1:8787/)，从“快速体验”进入[创作空间](http://127.0.0.1:8787/studio)。默认绑定本机127.0.0.1:8787，不能通过双击HTML运行正式应用。全站右上角可注册/登录（账号3—24位字母/数字/下划线、密码8—128位，账号不区分大小写；暂不支持找回密码）。默认每个账号可免费体验一次，既有手工测试配额保持。任何访客都可先点击“打开相机”，不需要选图、登录或云端确认，预览不上传、不占用次数。切到“映想画面”后，原画上出现动画悬浮卡；选择上衣图、确认云端处理、点击开始时才验证登录及权益，随后连接Decart。登录成功不会自动生成，需要再次主动点击。

结束/超时/连接失败会停止云端换装并回收模型输入克隆轨道，本机相机可继续预览。关闭相机、退出/切换账号、切后台或离开页面会关闭全部媒体；迟到授权或SDK结果也会清理，不自动恢复。移除最后一张参考图或取消云端确认只结束换装。仅采视频、不默认录制、不保存图片或视频；连接窗口可选15秒、30秒、1分钟，均由对应账号权益约束，无自动重连，长期密钥仅服务端。

上衣参考图现可一次多选或拖入、继续追加，当前页面最多6张，每张仍≤10MB。首次导入选中首张，追加不切换；点击缩略图在同一换装连接内更新衣服，不另占次数、不延长剩余时间。移除当前图自动选相邻图，移除最后一张才结束换装；刷新清空本次衣橱，不保存图片。工程与浏览器验证见[多图衣橱验收](docs/reports/2026-10-23-多图衣橱与会话换衣.md)，真实三图生成效果尚未复验。

仅填写密钥不会启用云端服务，还需frontend/.env.local中YINGXIANG_STUDIO_ENABLED=true。相机需要本机地址/HTTPS及可用设备权限；模型服务不可用不影响独立本机预览。云端告知版本已更新为2026-10-23-preview-cloud-v2，旧页面需刷新。实际验证与限制见[相机预览与换装交互](docs/reports/2026-10-23-相机预览与换装交互.md)。

时长选择在画面上方，连接开始后锁定，按15/30/60秒倒计时并主动断开，同时服务端向Decart签发相同maxSessionDuration限制；10秒token有效期只约束新连接，不会结束已连接会话。窗口含建连，不保证等长可见生成画面。免费15秒保留，长时需服务端durationQuotas对应次数；本轮未发放真实长时额度，维护规则见07第16节。检查结果见[三档时长验收](docs/reports/2026-10-23-三档时长与双层控制.md)。

```powershell
npm run typecheck
npm test
npm run build
npm start
```

以上命令均在 `frontend/` 中执行。服务启动后可在另一终端进入 `frontend/`，运行 `npm run smoke`，检查页面、生产资源、API模式与真实接口关闭状态。停止本地服务使用运行终端的Ctrl+C。

`npm run check`依次执行类型检查、逻辑测试与生产构建。提交锁文件，使用npm ci复现依赖。配置示例见 [frontend/.env.example](frontend/.env.example)，本地环境文件也放在 `frontend/`。页面加载、状态查询和组件准备不签发令牌或创建模型连接；只有主动开启真实体验才调用供应商。

GET /api/v1/config 和 /api/v1/health 可用；旧/api/v1会话、令牌及邀请接口仍返回503 SERVICE_DISABLED；本机账号与实际模型入口分别为/api/account/*与/api/studio/*。详细边界见 [接口契约与工程实现](docs/07-接口契约与工程实现.md)。

本机账号数据保存到frontend/.cache/accounts/store.json，含加盐scrypt密码摘要、会话摘要和免费权益/使用状态（含仅手工维护的测试配额quotas，默认每次账号1次）；不保存明文密码、会话Cookie、图片或视频。HttpOnly Cookie有效7天，退出可撤销；文件锁与临时文件替换保证单机并行写入。开发阶段请保留整个.cache/accounts目录，不要删文件重置权益。数据未加密，账号目录仅供本机开发，应按敏感文件保护与备份。

/api/studio/token现在要求有效登录、可用免费权益、同源及本机访问凭据。无效请求或相机失败不占用次数；已进入上游调用而结果不确定时待核查。免费一次按账号约束，当前未验证手机号，不能阻止重复注册。旧PoC及studio记录保留，实际链路仍无已验证的5美元硬账单上限；不开真实测试不产生模型费用。支付尚未开放。设计、迁移与本轮验证见[用户模块落地](docs/reports/2026-10-23-用户模块落地.md)。

## 首次真实模型验证记录

用户已于2026-10-23批准最多5美元，先执行一次短时测试。已安装固定版本Decart SDK0.2.12，首次通过当时的独立/poc页面验证；密钥只在frontend/.env.local。旧页面、API及开关现已移除；历史报告和本地操作记录保留。当前主页使用YINGXIANG_STUDIO_ENABLED及云端处理说明。

本轮标准档VTON 3.6、15秒单连接上限、一次令牌签发；关闭初次重试及可选遥测，失败后先核对用量。此为本机PoC，不提供公开登录、跨实例配额或已验证的账单硬限制。操作及限制见[首次真实模型测试操作](docs/09-首次真实模型测试操作.md)。

2026-10-23首批连接失败；用户另行批准的diagnosis-02已真实出画，首个远端播放观测3985ms、供应商事件秒数5、结束时本地轨道已关闭。用户确认上衣基本符合参考图，控制台截图汇总18 credits，尚未核实本次美元金额/计费秒数。原两批均已用完并保持锁定；用户后续另行要求主页不限手动次数，使用独立入口，不靠删除旧记录解除限制。首次验证详情见[真实模型接入验证](docs/reports/2026-10-23-真实模型接入验证.md)。

## 网站入口

- /：品牌宣传、实时换装介绍、使用步骤和快速体验。
- /pricing：15秒/30秒/1分钟 × 1/5/10次的拟定价格及计算器，付费尚未开放。
- /studio：原创作页面；访客可先选图，生成前同页登录，图片保留；登录后再次主动确认开始。
- /account：独立个人中心，显示本人权益、最近使用记录、订单空态与账号信息。

支付和长时付费购买尚未上线；普通新账号仍送一次15秒，30秒和1分钟必须有服务端单独发放的对应次数。不会因浏览价格或选中套餐发起模型连接。商业方案见[网站结构与商业模式](docs/11-网站结构与商业模式.md)。
