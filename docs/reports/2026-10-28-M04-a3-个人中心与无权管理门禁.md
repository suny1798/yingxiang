# M04-a3：个人中心与无权管理门禁

比较点63e57e7；关联FR13／14／18／39／40／43、T51-C01—03和M04-a任务卡。迁移/account、/account/usage、/account/security及/admin的匿名／普通用户门禁；订单和管理员控制台仍按M09处理，不把占位不可用状态计为控制台完成。

## 实现

AccountPage按原PersonalCenter的DOM层级、CSS、文案和页面边界迁移：匿名登录入口、读取失败／重读、本人权益概览、长时权益、最近20条使用记录、账号／注册日期和既有设置限制。保留北京时间格式、待核查／结束／连接异常／已申请状态，不添加改密、找回或手机号验证。页面只订阅公共账号协调器，不新增轮询；新身份到来时清空旧操作错误，不保留前一账号的详情。

/admin保留原匿名／普通用户无权限文案与登录／返回入口，导航只采用本人读取的role。管理员控制台本片尚未迁移，admin角色进入时仅显示暂不可用；M09必须替换这一分支并验全部管理操作，不可据此切流。

语言／主题使用Pinia setup store维护，复用原createPreferenceState和Cookie首屏、白名单localStorage同步逻辑；通过storeToRefs保持既有composable接口。Pinia偏好状态只有locale／theme，不引入全store持久化，不把账号、令牌或素材写入存储。公共页面和账号页面继续共用原偏好实例。
