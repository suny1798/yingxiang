# 映想

**让想象，在眼前发生。**

映想是一款面向实时画面创作的网页产品，规划通过提示词改变视频中的穿着、室内背景、宠物与摆件等内容。首个实现与验证场景为实时换装：选择上衣参考图、主动开启相机、观察生成画面并与原画对比。提示词及其他场景仍属于后续规划，尚未实现或完成模型验证。

当前已进入工程开发：Next.js + React + TypeScript 应用位于 src/，界面沿用雾白、暖灰与莓果红，模型层默认使用可取消的本地 Mock。尚未接入真实相机、模型、数据库或Redis，也未公开部署。Decart仍为候选，最终接入以PoC记录为准。

UI 审核可先打开 [本地预览](http://127.0.0.1:8765/prototypes/ui-v1/)；服务未运行时按 [原型运行说明](prototypes/ui-v1/README.md) 启动。原型不使用摄像头或模型。

## 启动应用

使用 Node.js 22+，在项目根目录执行：

```powershell
npm ci
npm run dev
```

打开 [映想应用](http://127.0.0.1:8787/)。默认绑定本机127.0.0.1:8787（本机3000端口不可用），不能通过双击HTML运行正式应用。选择参考图并确认处理说明后，点击“开启映想”体验Mock流程；工具栏可以模拟错误和连接恢复。

```powershell
npm run typecheck
npm test
npm run build
npm start
```

服务启动后可在另一终端运行 `npm run smoke`，检查页面、生产资源、API模式与真实接口关闭状态。停止本地服务使用运行终端的Ctrl+C。

`npm run check`依次执行类型检查、逻辑测试与生产构建。提交锁文件，使用npm ci复现依赖。配置示例见 [.env.example](.env.example)；本阶段不需要API Key，即使配置真实密钥也不会启用供应商调用。

GET /api/v1/config 和 /api/v1/health 可用；真实会话、令牌及邀请接口明确返回503 SERVICE_DISABLED。详细边界见 [接口契约与工程实现](docs/07-接口契约与工程实现.md)。

## 当前推进顺序

1. 按需求基线推进，记录目标地区、设备与预算等待确认的事项。
2. 在无密钥条件下细化交互原型、Mock 场景和评估样本清单；原型不得显示虚构的真实试穿结果。
3. 有模型账户和明确测试预算后执行限额 PoC，记录实际网络、效果、时延和账单。
4. 依据 PoC 收敛技术设计，再逐个完成开发任务与验收。

项目设计使用 Markdown 维护，正式应用使用TypeScript；Word文件不作为后续执行入口。prototypes/ui-v1保留为设计参考，运行应用以src/和npm脚本为准。

Git 已初始化。用户已授权后续在改动完整、验证通过时自行创建规范的本地提交，采用 `feat/fix/docs` 等类型，不自动推送或公开发布。
