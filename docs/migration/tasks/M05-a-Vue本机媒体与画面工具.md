## 生命周期及验收

本机流、克隆流、视频元素srcObject、本机URL和导出任务都有明确所有者。订阅和全局监听卸载成对；取消后的迟到流立即停轨，退出／换账号／角色变化由SessionScope清理回调停止旧资源，跨标签transitioning也拒绝旧异步结果。单纯登录成功保留仍有效素材且不自动生成，按16已有规则处理，不自行扩展留存。
