# M08-b：Vue提示词组合实时编辑

前置M05画面工具、M06作品详情提示词读取、M07实时会话与M08-a视频提交通过；当前状态只在05维护。关联FR24／31／46、T24／32／47与16附录A.3／A.4，沿用当前worktree/frontend，原工作区及正式入口不切换。

## 输入与行为切片

`/studio/edit`在保留原PromptStudio视觉、文案、键盘与分页的基础上，接入既有`PromptSession`、`DecartPromptAdapter`、相机与远端预览：

- 草稿不自动发送；添加提示词时校验每条1—500字、本次最多12条，并按当前顺序合成完整组合；分页每页1／2／3条，Ctrl／Cmd+Enter发送。
- 登录门禁、云端处理确认与主动开始：未登录先打开账号弹窗；打开相机、添加提示词、勾选云端处理后点击“开始实时编辑”才建连。
- 仅读取状态、签发令牌、SDK建连或收到远端流都不开始倒计时；远端生成视频实际播放后才进入live并启动15秒，连接等待另设30秒超时。切到相机原画不暂停云端处理。
- 同一次连接内增删只同步最新完整组合，不重签、不续时、不扩大费用授权；快速连续增删由既有控制器串行合并。移除全部提示词结束生成并显示相机原画。
- 生成画面默认录制无声流并分片保存为`edit`作品，同时保存本轮已同步的提示词组合；未发送草稿不保存。作品详情“本次提示词”沿用M06-b读取，旧作品无留存不能补回。
- 镜像、全屏、当前帧PNG沿用现有画面工具；作品回放与下载沿用M06详情工具。账号／角色变化、隐藏、离开页面或卸载停止连接、相机与录制，迟到结果不进入新账号；不自动重连。
- `suny`测试账号例外仍由后端现有配置控制；本片不新增或扩大账号权限、预算、令牌或供应商调用。

## 验收

- 单测新增Vue提示词编排：组合增删与12条上限、全删结束回原画、同连接增删不重签／不续时、账号切换清空与停止、隐藏清理、未确认／未开相机不开始且草稿不写历史；既有prompt／session／录制／作品上传测试全部回归。
- 浏览器在1440×1000桌面使用临时SQLite旧FastAPI（8790）与8791生产构建preview，注册合成账号；SDK、`/api/prompt/status`、`/api/prompt/token`按实际路径使用明确替身，作品保存走真实临时作品接口。验证打开相机、添加两条提示词、确认后开始、延迟远端首帧后计时、同连接增删不重签、全删结束回原画、提示词历史保存与作品详情回看、镜像／全屏／PNG、离开清理及无模型／支付真实调用。
- 既有local-studio、local-studio-tools、local-video-studio、studio-session、works-index、video-jobs桌面脚本回归；`npm run check`、`legacy:typecheck`、`npm run smoke`通过。

## 边界

- 浏览器中的相机、SDK、状态与令牌均为合成／路由替身；生成画面来自canvas，没有真实相机、真实供应商、真实令牌、真实出画或提示词效果结论，也没有真实计费／账单核对。
- 提示词历史保存使用真实临时作品接口，但不是正式用户数据，不能替代生产迁移或真实作品验收。
- 真实供应商调用、正式入口切换与G1仍归后续；不修改API、数据库、权益或正式作品；不push、不切流。
