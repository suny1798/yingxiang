# 首页左侧扩图与夜间接缝

关联FR36/T37；2026-10-25。用户要求左侧加宽、右侧人物不变。

## 根因与实现

原图1672×941，按height:100%/width:auto并靠右显示，浏览器比图片显示比例更宽时，左侧暴露frame底色。深色遮罩使图片左边缘的亮度变化变得明显。

采用官方内置image_gen工具，以四张v3原图逐张编辑。实际原生输出均为2172×724（3:1），请求中较大尺寸未被工具采纳，不宣称3000px原生。Sharp仅转为quality92/effort6的WebP，不缩放或编辑人物。新资产：

| 场景 | 项目内文件 | 字节 |
| --- | --- | ---: |
| 相机换装 | frontend/public/assets/home/hero-live-left-v4.webp | 290712 |
| 视频换装 | frontend/public/assets/home/hero-video-left-v4.webp | 229504 |
| 提示词编辑 | frontend/public/assets/home/hero-prompt-left-v4.webp | 263882 |
| 创作工作台 | frontend/public/assets/home/hero-workspace-left-v4.webp | 258278 |

为避免生图重绘右侧细节，页面以扩图铺底，同时继续用原v3图片覆盖右侧。原图文件、height:100%/width:auto/right:0的几何关系不变，仅左侧0—32%空景渐入；所有人物、服装参考、时间线、提示词卡片区域使用原图。扩图层width:100%/height:100%/object-fit:cover，在超宽屏裁切时也仅影响底层新增背景。原图顶部/底部边缘柔化移到共同frame。标语、其余首页文字和轮播交互不变。新增装饰图片alt为空且aria-hidden，原有概念图说明保留。

## 后续纠正：撤销双图合成

用户提供更宽浏览器截图，显示柜子、屏幕及杯子有双影。原因是v3原图和v4扩图的物体位置不完全相同，页面叠加两幅图并做透明渐变，不能保证像素对齐。上一轮1280px检查不足以证明所有宽度下无重影，其结论不适用于用户当前宽屏。

最终改为每张幻灯片仅一幅完整宽图，删除原图覆盖层和横向透明拼接。纯色日夜遮罩与垂直边缘柔化保留，不再合成两套景物。人物与场景改为使用完整扩图自身的版本，不再宣称显示v3原始像素。男士场景沿用v5宽图，其他三张沿用v4宽图。后续构建和页面结构验证结果记录在任务验收文档。
