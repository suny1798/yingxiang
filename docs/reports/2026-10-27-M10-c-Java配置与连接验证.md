## 真实连接检查

独立CLI通过最终可执行Jar的PropertiesLauncher启动ConnectionProbe，使用现有Maven管理的JDBC42.7.14／Lettuce7.5.2.RELEASE。不是Python套接字代替Java连接，也不启动Web或Flyway。

```powershell
# backend/；本轮仅执行一次真实连接
.venv/Scripts/python.exe -m scripts.java_connections
```

外层截止45秒；PG连接5秒／socket6秒／login8秒、查询5秒，Redis连接5秒／命令6秒，禁止自动重连。PG保持verify-full，Redis保持TLS及peer验证；驱动握手失败后不降级协议、不继续无TLS认证。

| 服务 | Java实际结果 | 耗时 | 能得出的结论 |
| --- | --- | --- | --- |
| PostgreSQL | TLS_NOT_SUPPORTED | 169ms | 目标入口拒绝TLS；未到成功认证或只读SQL |
| Redis | CONNECTION_OR_TLS_TIMEOUT | 7901ms | TLS连接阶段超时；未成功认证或PING |

命令退出1，表明依赖未通过；不是配置工具崩溃。PG预设验证仅在认证成功后以只读事务查询服务版本、隔离schema存在性和transaction_read_only，当前均未执行。Redis成功时仅认证／PING及客户端必要握手，不读写业务键；测试命名空间ACL写权限不在本片验证范围内。

本轮没有发送公网明文密码、关闭TLS、重试SSH、修改宝塔或服务配置、创建库／schema、执行DDL／Flyway、查询账号／作品或触发真实模型／支付。账号密码正确性、库存在性、schema和权限仍未得到验证。
