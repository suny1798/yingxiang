# M14：已有视频任务闭环

父片M14，关联FR23／26、NFR06—08及T51-C05／11。依赖M12账本与M13的隔离入口；Vue入口与正式切流未迁移，不认定G2。

本轮功能：迁移旧视频换装的输入校验、内存去音轨、独立预算预留、供应商提交与查询。`POST /api/video/prepare`无需登录，按`video/mp4`读取≤25MB，拒绝非普通MP4，只复制画面chunk并重建索引，返回`X-Video-Audio-Removed`；`POST /api/video/jobs`要求本人会话、精确来源、`X-Video-Attempt`、同意版本、单画面H.264、16:9／2:1或9:16／1:2、320—3840像素、1—15秒、≤10MB JPG／PNG／WebP静态参考图；解析失败不占预算。预留与`video_jobs`、`budget_reservations`同事务，按场景行锁串行化全局上限；供应商提交只发生一次，失败保留unknown，重复提交编号不重POST；查询按3秒节流，只接受pending／processing／completed／failed且job_id匹配；结果下载仅本人、窗口内、完成态，最多200MiB。

实现方式：Spring JDBC＋真实PostgreSQL；`Mp4`与`Multipart`为有界内存实现（无临时文件）；Servlet multipart预解析显式关闭，避免Spring/Tomcat在进入控制器前消费或落盘请求体。供应商端口只允许回环地址，配置项`migration.video-*`默认关闭。

验收：随机临时schema；真实PG＋两Java进程＋本机合成视频供应商；48项检查覆盖未登录状态、去音轨字节、passthrough、非法媒体／类型、提交鉴权与编号、单次POST与字段、重复编号、单活动任务、3秒节流与完成、结果下载与附件、他人404、预算上限、上游失败unknown与不重POST、unknown阻断、管理概览真实预算／次数、任务列表、重启后持久且无重POST；51项JUnit含MP4真实样片、图片头校验与multipart边界。M10—M13回归同批通过。

边界：合成供应商不代表真实模型效果／费用；作品保存与Worker收取结果留M17；概览prompt预算仍为M16前空值；未改V1、未连正式库、未调用真实模型、未切换8787／8788。证据见[报告](../../reports/2026-10-29-M14-已有视频任务.md)。
