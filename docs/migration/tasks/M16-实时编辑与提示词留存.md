# M16：实时编辑与提示词留存

父片M16，关联FR24／31／46、NFR06—08及T51-C05—07。依赖M12与M15；Vue入口与正式切流未迁移。

本轮功能：迁移实时编辑门禁与提示词留存。

- **编辑门禁**：`GET /api/prompt/status`按服务开关、暂停、允许用户名、unknown等待窗口、预留租约、次数与预算返回available／message；可用且已登录时返回编辑访问nonce。`POST /api/prompt/token`要求本人会话、精确来源、`X-Studio-Access`、固定同意版本与15秒；按attempt ID幂等拒绝，预留US$0.30与45秒租约，预算上限0.3—5美元、1—20次；合成令牌服务签发后校验模型／来源／时长与永久密钥隔离，成功置issued，失败保留unknown与预算并记录脱敏诊断，不自动重试。`suny`例外只按配置的用户名生效：允许列表外的账号仍被拒绝，无限次只跳过次数／预算检查，不绕过登录、来源、访问凭据与暂停。
- **提示词留存**：`GET /api/works/{id}/prompts`与`POST /api/works/{id}/prompts/{index}`只对本人edit作品；状态含`atMs`（0—15000）与1—12条1—500字符提示词；同index同内容幂等、不同内容409、乱序409、非capturing新增409、空数组／超长400、32KB请求与4MB历史上限；文件写入作品私有目录，随作品删除；旧作品无历史返回空态。
- 前端“同连接组合、默认保存”已在M09提交中验收；本片只迁移服务端合同，不改前端行为。

验收：随机临时schema＋独立临时存储；真实PG＋两Java进程＋合成令牌服务；36项检查覆盖匿名／允许列表／访问凭据、固定15秒与同意、成功签发与issued／预留、重复ID、次数上限、上游失败unknown与诊断、不自动重试、等待窗口、suny例外不扩大、提示词空态／写入／幂等／冲突／乱序／长度／Content-Type／非edit空态、重启持久、删除后404；54项JUnit与M15回归同批通过。
