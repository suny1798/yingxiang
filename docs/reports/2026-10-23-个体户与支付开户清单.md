# 个体户与支付开户清单（个人开发者 · 中国大陆）

日期：2026-10-23
适用：映想当前为个人开发、无商家资质，准备从“免费体验”过渡到“内测收费”。
不构成法律、税务或支付机构的准入承诺；所有材料、费率与审核结果以属地政务平台和微信/支付宝官方审核为准。

## 0. 先分清四个门槛

支付开户只是其中一个，且不是最难的：

| 门槛 | 解决什么 | 个体户能否解决 | 备注 |
| --- | --- | --- | --- |
| 营业执照 | 微信普通商户、支付宝电脑网站支付的主体资格 | 能 | 线上可办，1—3 个工作日 |
| ICP 备案 | 境内服务器 + 域名合法提供网站服务；微信 PC 网站支付要求已备案域名 | 能 | 免费，7—20 个工作日 |
| 经营性 ICP 许可证 | 若被认定为“有偿互联网信息服务” | **不能** | 仅企业法人可申请，通常要求注册资本 ≥100 万；个体户/个人不行 |
| 生成式 AI 备案/登记 | 面向境内公众提供 AI 生成内容服务 | 需进一步确认 | 调用境外模型（Decart）无法走“已备案模型”路径，且涉及数据出境 |

**关键提醒：** 如果目标是公开、持续地向不特定公众收费，个体户可能不足以覆盖“经营性 ICP 许可”和生成式 AI 合规；这种情况下应评估注册有限责任公司，而不是只办个体户。若只是小范围内测、不公开推广，个体户可以先解决支付开户，但不能据此宣称整体合规。

## 1. 主体选择：个体户还是有限公司

| 对比项 | 个体工商户 | 有限责任公司 |
| --- | --- | --- |
| 注册成本 | 线上多为 0 元 | 0—1000 元（自办/代办） |
| 注册时间 | 1—3 个工作日 | 3—10 个工作日 |
| 注册资本 | 无 | 认缴制，ICP 许可证通常要求 ≥100 万 |
| 记账报税 | 2000—3000 元/年（可自行申报） | 3000—6000 元/年 |
| 银行账户 | 可开对公，也可绑定经营者个人卡 | 必须对公 |
| 微信普通商户 | 支持 | 支持 |
| 支付宝电脑网站支付 | 支持 | 支持 |
| 经营性 ICP 许可证 | **不可申请** | 可申请（需满足人员、社保、场地等要求） |
| 适合阶段 | 小范围内测、验证付费意愿 | 公开运营、长期收费、需要许可 |

**建议：** 先用个体户完成支付通道和内测验证；如果确定要公开推广，再升级为公司。不要用个体户长期承接需要 ICP 许可证的经营性业务。

## 2. 个体工商户注册清单

### 2.1 准备材料

- [ ] 经营者身份证正反面照片
- [ ] 经营者实名手机号
- [ ] 经营场所证明：自有房产证/租赁合同/市场摊位证明等；部分地区允许住宅“住改商”，需按属地要求提供证明
- [ ] 3—5 个备选名称（格式：行政区划 + 字号 + 行业 + 组织形式，如“XX市映想技术服务部”）
- [ ] 经营范围（见 2.3）
- [ ] 银行卡（用于后续结算）

### 2.2 办理渠道

- 属地政务服务网/APP（如“一网通办”“浙里办”“粤商通”“e窗通”等），搜索“个体工商户设立登记”。
- 也可到街道/市场监管所窗口办理。
- 审核通过后领取电子营业执照；纸质执照可邮寄或现场领取。
- 多数地区免费，刻章部分地区免费或 0—200 元。

### 2.3 经营范围建议（按属地规范勾选）

优先选择与“软件/技术服务”相关的规范表述：

- 技术服务、技术开发、技术咨询、技术交流、技术转让、技术推广
- 信息技术咨询服务
- 数字内容制作服务（不含出版发行）
- 互联网销售（除销售需要许可的商品）
- 广告设计、代理；广告制作；广告发布（非广播电台、电视台、报刊出版单位）
- 软件开发；信息系统集成服务；数据处理服务

避免自行加入需要前置/后置许可的项目（如“互联网信息服务”“增值电信业务”“网络文化经营”“出版物经营”等），除非已确认取得相应许可。经营范围最终以登记机关规范目录为准。

### 2.4 注册后 30 天内

- [ ] 税务报到/登记（电子税务局）
- [ ] 确认纳税人类型（小规模纳税人/一般纳税人）
- [ ] 了解申报周期：小规模纳税人通常按季度申报增值税及附加税；经营所得按年汇算
- [ ] 开立银行账户（对公或个体户结算户），或确认使用经营者个人卡结算
- [ ] 保存执照、印章、银行开户资料
- [ ] 如做线上业务，同步启动域名注册与 ICP 备案

## 3. 微信支付普通商户开户清单

### 3.1 前置条件

- [ ] 个体工商户营业执照（在有效期内）
- [ ] 经营者身份证
- [ ] 结算账户：对公账户或经营者个人银行卡（个体户可选对私）
- [ ] 已 ICP 备案的域名与可访问的 PC 网站（微信 PC 网站接入要求）
- [ ] 一个已认证的 AppID：个体户主体的微信小程序或服务号（认证费 300 元/年）；Native 下单需要绑定 AppID
- [ ] 网站内容、商品/价格、退款规则、客服联系方式可公开展示
- [ ] 经营类目与网站实际内容一致（AI 图像/视频服务需如实选择类目，必要时补充资质）

### 3.2 申请步骤

1. 注册微信支付商户号：<https://pay.weixin.qq.com>，选择“成为商家/普通商户”。
2. 主体类型选择“个体工商户”，上传营业执照、经营者身份证、结算账户。
3. 填写超级管理员（经营者或经办人）、客服电话、经营类目、商户简称。
4. 提交后 1—2 个工作日审核；通过后在线签约。
5. 绑定 AppID（小程序/服务号），开通 Native 支付。
6. 配置 APIv3 密钥、商户 API 证书、微信支付公钥。
7. 配置回调域名（必须 HTTPS、公网可达）。
8. 用 0.01 元真实订单联调：下单 → 扫码支付 → 回调验签 → 查单 → 退款。

### 3.3 费率与结算

- 费率约 0.6%，按经营类目可能为 0.6%—1%。
- 结算 T+1 到结算账户。
- 退款、对账、投诉处理均在商户平台完成。

### 3.4 常见卡点

- 没有已备案域名：PC 网站支付无法通过。
- 没有已认证 AppID：Native 下单缺少 appid，无法完成绑定。
- 网站内容与类目不符：会被要求补充资质或驳回。
- 个体工商户名称与网站主体不一致：需在网站底部展示主体信息。
- 新商户短期内大额交易：可能触发风控，建议小额起步。

## 4. 支付宝开户清单

### 4.1 当面付（可先开，个人/个体户）

- [ ] 支付宝账号实名（个人或个体户）
- [ ] 店铺/经营名称、经营地址
- [ ] 经营场景照片（门店/办公室/工作场景；线上业务提供网站截图、域名、ICP 备案信息）
- [ ] 营业执照（个体户建议提供，可解除额度限制）
- 入口：支付宝商家平台 → 产品中心 → 当面付 → 签约
- 费率约 0.6%；个人无照基础版单笔 ≤1000 元、单日 ≤5 万元；有照个体户可申请不限额度版本。
- 注意：当面付官方定位线下扫码，网页订单转二维码存在场景复核风险；有照后优先用电脑网站支付。

### 4.2 电脑网站支付（个体户可签）

- [ ] 个体工商户营业执照
- [ ] 已 ICP 备案、可正常访问的网站
- [ ] 网站展示商品/价格、退款规则、隐私政策、客服联系方式
- [ ] 支付宝开放平台创建应用，签约“电脑网站支付”
- [ ] 配置应用私钥、支付宝公钥、回调地址（HTTPS）
- 费率约 0.6%；异步通知 + 主动查单；支持退款。
- 手机端可配合手机网站支付（同样要求企业/个体户）。

### 4.3 联调

- 先用支付宝沙箱验证签名、金额校验、重复通知、退款。
- 再用 0.01 元真实订单验证到账与回调。
- 回调必须校验 `app_id`、`seller_id`、`out_trade_no`、`total_amount`、`trade_status`。

## 5. ICP 备案清单

- [ ] 域名已完成实名认证，且域名后缀在工信部许可范围
- [ ] 境内云服务器（阿里云/腾讯云/华为云等），取得备案服务码
- [ ] 主体资料：个体户营业执照、经营者身份证
- [ ] 网站负责人身份证、手机号、邮箱
- [ ] 网站名称、服务内容、域名列表
- [ ] 真实性核验（人脸识别/幕布拍照，按接入商要求）
- [ ] 网站底部展示备案号并链接工信部
- 流程：接入商初审 → 短信核验 → 省通信管理局审核 → 下发备案号
- 时间：通常 7—20 个工作日，各省不同；期间网站不能对外开放访问（可按接入商要求放置备案中页面）
- 备案免费；云服务器与域名另计

**注意：** ICP 备案 ≠ ICP 许可证。备案只解决“网站可以合法上线”，不解决“有偿信息服务”的经营许可问题。

## 6. 建议时间表

| 时间 | 事项 | 依赖 |
| --- | --- | --- |
| D0 | 确定主体类型（个体户/公司）、准备材料 | 本文第 1—2 节 |
| D1—D3 | 提交个体户注册 | 身份证、地址证明、名称 |
| D3—D5 | 领取执照；税务报到；银行开户（如需） | 执照 |
| D3—D7 | 注册域名、购买境内服务器、提交 ICP 备案 | 执照 |
| D5—D10 | 注册并认证小程序/服务号（300 元/年） | 执照 |
| D7—D12 | 申请微信支付商户号、支付宝当面付/电脑网站支付 | 执照、备案进度、AppID |
| D12—D20 | ICP 备案下号；配置 HTTPS 与公网回调 | 服务器、域名 |
| D14—D21 | 0.01 元真实联调：下单、回调、查单、退款 | 商户号、证书、密钥 |
| D21+ | 小范围内测，观察风控、退款、投诉 | 全部就绪 |

ICP 备案和商户审核可并行推进；微信 PC 网站支付最终受备案下号时间约束。

## 8. 上线前检查清单

- [ ] 营业执照、税务登记、银行账户就绪
- [ ] 网站底部展示主体名称、备案号、客服联系方式
- [ ] 用户协议、隐私政策、退款规则、未成年人条款可访问
- [ ] 商品价格、时长、次数、有效期、退款条件写清楚
- [ ] 支付密钥只在服务端环境变量，未进入前端或日志
- [ ] 回调地址为 HTTPS 公网地址，验签与金额校验已测试
- [ ] 重复回调、乱序回调、回调丢失（主动查单）均已覆盖
- [ ] 退款流程与已使用次数的扣回规则已确定
- [ ] 发票口径已确定（个人代开/个体户自开）
- [ ] 生成式 AI 备案/登记与数据出境评估已有结论
- [ ] 小额真实支付测试完成，未出现重复发权益

## 9. 不建议的做法

- 用个人收款码收取远程经营款，或用手机监听、V 免签、截图认款。
- 借用他人营业执照或代注册 Stripe/Paddle。
- 用微信小微商户承接线上 AI 服务（官方明确不支持线上虚拟行业）。
- 只做 ICP 备案就宣称“已完成经营性合规”。
- 在未确认生成式 AI 与数据出境要求前公开推广。

## 10. 待确认

1. 目标是“小范围内测”还是“公开持续收费”？前者个体户可先行，后者需评估公司 + ICP 许可证。
2. 是否接受每年 2000—6000 元的记账与主体维护成本？
3. 网站是否已有可备案的域名与境内服务器？
4. 生成式 AI 备案/登记由谁负责，Decart 境外模型的数据出境如何评估？
5. 是否需要向用户开具发票？开票主体与税率如何设置？
