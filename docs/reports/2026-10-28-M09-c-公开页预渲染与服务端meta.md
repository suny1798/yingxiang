# M09-c：公开页预渲染与服务端meta

比较点074cd71；关联M09、FR34—42／NFR09、T51-C02／11及[16附录A.2／7.3](../16-前后端技术与架构迁移执行方案.md)，任务卡见[M09-c](../migration/tasks/M09-c-公开页预渲染与服务端meta.md)。本片补齐M09-b遗留的“客户端标题不等价于服务端meta”，六个公开页在构建期生成服务端HTML与分享标签，私有页保持SPA并noindex。**入口切换未执行**，等待用户授权。

## 实现

采用构建期静态预渲染，不新增常驻Node SSR服务，入口仍是Nginx静态文件＋`/api`代理。

- 新增`src/vue/route-data.ts`：公开／私有路由与标题、描述、robots的单一来源，并导出`pageTitle`；`main.ts`的路由meta改为引用同一张表，避免页面标题出现第二份。
- 新增`src/vue/document-meta.ts`：标题／描述／robots的纯函数与`applyDocumentMeta`。`App.vue`改为调用它，客户端路由变化时同步`description`、`robots`、`og:title`、`og:description`、`twitter:title/description`，私有页切到`noindex, nofollow`。
- 新增`scripts/prerender.ts`（`tsx`执行）：把`vite build`产出的入口壳复制为`dist/app.html`并注入`noindex`；启动仅回环的临时静态服务，对`/api/account/me`、`/api/site/announcement`、`/api/payments/status`返回匿名只读替身；用本机Chromium无头浏览器`--dump-dom --virtual-time-budget=3000`逐路由抓取；校验标题、`lang="zh-CN"`、`#app`、`<main>`、每页关键正文、匿名“登录 / 注册”且无“账号读取中／重新读取账号”等瞬时占位；移除抓取时客户端写入的动态标签后统一注入description、robots、OG、Twitter（设置公开Origin时再加canonical、og:url、og:image）；写出`dist/index.html`与`dist/<path>/index.html`，并生成`dist/entry-routes.json`。
- `vite.config.mts`新增仅用于preview的入口中间件，按`entry-routes.json`把公开页指向各自HTML、私有页指向`app.html`并带`X-Robots-Tag`、未知路径返回404＋壳，使preview与Nginx合同一致。
- `deploy/nginx.local.conf.template`：新增`$entry_robots`映射（`/app.html`、`/account*`、`/admin`、`/studio*`、`/works`→`noindex, nofollow`，空值不发送）；首页固定`/index.html`，新增`/app.html`；`try_files $uri $uri/index.html /app.html`，404仍交`app.html`。
- `vue-smoke.mjs`改为逐页断言服务端meta与正文、私有页壳与404；`nginx-contracts.mjs`改为按文件比对六个公开页、私有页壳与`X-Robots-Tag`；新增`tests/public-metadata.test.ts`（5项）。

依赖与版本：**未新增npm依赖**。构建期使用已锁定的`tsx 4.23.15`运行脚本；无头浏览器为本机Chrome `156.0.8078.48`，可用`YINGXIANG_CHROME_BIN`指定，找不到即中止构建。`YINGXIANG_PUBLIC_ORIGIN`未设置时省略canonical、og:url与分享图绝对地址，不使用虚构域名；分享图沿用既有`/assets/try-on-demo-poster.jpg`，不是本轮新制的分享卡片。

## 边界与未覆盖

- 构建机需要Chromium内核浏览器；未接入持续集成，缺失浏览器时构建失败而不是降级为空壳。
- 未设置公开域名，故未生成canonical、og:url与绝对分享图；分享图沿用既有演示海报，未新制社交卡片。设置`YINGXIANG_PUBLIC_ORIGIN`后需复跑构建核对。
- 英文仍是同一URL的客户端切换，抓取器只看到中文默认meta；未生成英文静态页，也未验证真实搜索引擎收录。
- 未覆盖手机端、跨浏览器、CDN／生产Nginx、TLS与缓存头实测；Windows版Nginx验证不代表Linux／HTTPS门槛。
- 预渲染抓取使用匿名接口替身，页面在真实账号、启用公告下的首屏仍由客户端补齐；公告与账号状态不属于服务端HTML。
- 未创建Git提交、未push、未停止或替换8787 Next、未改正式Nginx与生产配置。
