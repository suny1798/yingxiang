# M03-a7：Nginx隔离入口合同

比较点03f7ef8；关联M03／M09、FR34—42／NFR09、T51-C02／11及[M03-a任务卡](../migration/tasks/M03-a-Vue公开浏览与工程边界.md)。本片交付可复跑入口模板和HTTP合同工具，公共布局继续独立批次。

## 实现与验证

本机已有Nginx1.28.3。工具只使用自建临时prefix／配置、随机回环端口和合成Node HTTP上游，未修改安装目录配置、原服务、宝塔或正式入口。已修正Nginx正则含花括号时的引用及Windows临时路径准备，配置先经真实nginx -t检查，再实际启动执行请求。

`frontend/` 下 `npm run smoke:nginx` 实际通过47项断言：六个公开页面和查询直达200／no-store；未知页面HTTP404且保留Vue入口；哈希JS的MIME／immutable／304；缺失资源404且无SPA回退／无缓存；未知API的404 JSON；chunked原始字节SHA256、multipart boundary、原始查询编码和重复参数；Host／Origin／Cookie与两条Set-Cookie；业务签名／所有权／代次头；伪造Forwarded头清除及重建；上游401／403／409／429／503及Retry-After透传；GET／HEAD Range206及长度／ETag／下载名、416、If-Range回退200；两种本机Host允许与伪造Host403；声明超限413；结果未知的POST断开503且上游只收到一次；上游停止时受控503。

合成写入echo一次、断开POST一次，没有自动重试；真实模型和支付调用为0。退出后临时prefix已清理，工具进程退出0。合成上游只证明传输和状态合同，不证明真实后端授权、账务或媒体效果。浏览器实际Nginx入口走查随完整公共布局继续，不能以本报告的HTTP断言替代。

## 审查与边界

Spec与Standards为同Agent自检，非独立Review。页面、缓存和传输行为有真实Nginx证据；不改变业务API，不含私有配置，不向日志写原始请求。公开页仍未完成全站公共布局；M03／G1均未标为通过。

35MiB＋4096字节为外围上限；逐接口上传限制、上传中断及业务总截止仍待M09。130秒为Nginx读写空闲间隔，未冒称总截止。Windows版本不能代表Linux／HTTPS生产门槛。按用户授权单独本地提交，不push、不切流；运行说明见[入口说明](../../frontend/deploy/README.md)。
