# 首页默认示意图与换衣动画

日期：2026-10-23；状态：已接入并本地验证，等待用户审核，未提交。

## 改动

- 右侧画面区：相机未开启时循环播放「镜中换衣」示意动画（9 秒）。女性角色站在拱形镜前，左侧衣橱缩略图被点击后飞向领口，收成 ✳，展开成莓果红扫描线从领口扫到下摆，上衣随之换成新的一件。三次换衣依次为云白衬衫 → 莓果针织 → 苔绿外套 → 云白衬衫，节奏一次比一次快，结尾留一段静止，首尾无缝循环。
- 左侧上传区：空状态显示挂在衣架上的云白衬衫（与动画第一件同款），并补充提示「平铺或挂拍的上衣图效果更好」。
- 画面左下角为引导卡：宋体标题「打开相机，换上你选的上衣」、说明「上方为示意动画，不是实际生成效果」和「打开相机」主按钮。最初用 10px 小标签，用户反馈新访客看不到，改为卡片（桌面标题 18px、按钮 13px）。仅在「相机原画」视图显示；切到「映想画面」时由原有浮层卡接管，不会重复。
- 打开相机后仍停在「相机原画」时，画面左下角换成第二张引导卡「相机已开启，切到映想画面」，副文案按是否已选上衣切换，主按钮「切到映想画面」直接切换视图；同时底部「映想画面」标签着莓果粉底并做呼吸外圈（减少动态时改为静态描边）。切换后引导卡和标签提示消失，由原有浮层卡继续引导选图、确认与开始换装。换装进行中不显示。
- 顶部导航删除「快速体验」按钮及其样式 `.smallCta`（用户要求），入口改由导航中的「创作空间」和首页内的按钮承担。
- 系统开启「减少动态效果」时只显示静态首帧。手机竖屏改为 contain 并放大，保证衣橱缩略图（换衣的起因）不被裁掉。
