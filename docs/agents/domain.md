## 领域词汇

| 术语 | 在本项目中的含义 |
| --- | --- |
| 实时换装／视频换装／实时编辑 | 当前三个创作场景，各自有生效的媒体、时限和服务端门禁，不能混为新助手 |
| 权益／grant／流水 | 服务端发放、预留、使用、撤回账本；沙盒权益与real_usage隔离 |
| unknown／风险预留 | 外部收费操作结果未知仍保留的使用或预算占用，不因lease到期、迁移或重启自动释放 |
| lease／代次 | 限时执行占位与旧执行者识别，不能代表额度退款或外部请求恰好执行一次 |
| 作品 | 本人生成结果及授权保存的参考图／提示词历史；不包括原相机和输入人物视频 |
| M切片 | 2.0方案中可独立验证的迁移工作；状态在05，任务卡在docs/migration/tasks |
| G0—G4 | 技术集成与切换条件，与Brainstorm等工作流阶段是不同维度 |
| Spec／Standards | 分别审查需求符合度与工程约定，互不抵消 |
