## 4. 发布条件

受邀内测发布前：

- 全部 P0 已验收，无阻塞或高严重度缺陷；真实质量指标达标或已记录有依据的范围调整。
- 支持矩阵中的设备实际通过；未测手机不列入支持。
- 长期密钥不在前端/仓库/日志；图片、媒体、令牌及邀请码不出现在非预期留存。
- 用户说明与实际数据路径一致；第三方条款、权限和额度已核实。
- 预算、停发开关、供应商限制、风险预留和账单对账可操作。
- 发布清单关联代码提交、SDK、模型、提示与配置，预发布通过且回滚步骤可执行。

公开发布还需解决主文档第9章的供应商侧预算/连接控制和第16章的上线条件。受邀内测通过不自动等于允许公开服务。
