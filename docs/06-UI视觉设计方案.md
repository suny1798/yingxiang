## 1. 视觉方向

用户要求：简约、有个性、浅色，不使用常见技术产品的蓝色主视觉。

项目正式名称为「映想」，品牌标语为「让想象，在眼前发生。」。整体定位为实时画面创作，首个体验场景为实时换装；现已增加视频换装和提示词实时编辑。下文人台插画及示意交互描述为早期原型记录，具体扩展效果仍以实际功能范围为准。

本版采用“浅色创作空间”：雾白页面、暖灰画面区、炭灰文字、少量莓果红交互。品牌用中文宋体字标，主标题展示完整标语。当前换装场景继续使用拱形预览区和裁衣人台插画，其余区域保持克制，便于以后扩展其他场景。

原先线框的上传与视频两区结构保留；将视觉重心进一步放到试衣镜，去除不必要的信息卡片。未增加商城、云端衣橱、下载、付费或实际模型接入。

参考访问日期：2026-10-22。当前界面是针对试衣工具重新设计，没有复制参考站的页面源码、品牌或服装摄影。原型插画和图标是项目内的 SVG；正式前端的拉丁字体已于2026-10-29改为随站点托管的 Inter，不依赖外部字体服务。

## 3. 设计令牌

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 雾白 | `#F8F7F4` | 页面背景 |
| 纸白 | `#FFFEFA` | 上传区及试衣面板 |
| 炭灰 | `#292622` | 主要文字 |
| 暖灰 | `#756F69` | 次要说明 |
| 莓果红 | `#793D50` | 开始按钮、选中状态、链接与焦点 |
| 浅莓粉 | `#F0E3E6` | 轻提示与结束按钮底色 |

分隔线 `#E5E1DC`，试衣舞台 `#EEEBE6`。苔绿仅用于状态点和示意服装，不成为第二套品牌主色。纯白与炭灰的色差用于内容层级，避免大量阴影和渐变装饰。

2026-10-29用户确认希望中文也具有英文Inter的利落观感，中文「映想」字标、标题、正文和表单统一改为本地托管的Noto Sans SC（简体中文无衬线，Google Fonts v41发行）；中文缺字回退PingFang SC／Microsoft YaHei。英文、数字和英文品牌名继续使用本地托管的Inter 4.1 → Helvetica Neue → Arial。正文与展示标题分别由--font-body／--font-display控制，两者共用无衬线体系，启用字体光学尺寸。标题字重600，英文标题字距-.02em、主标题-.035em，中文标题字距0；品牌字重600，英文字距-.03em、中文字距0；常规正文400，英文段落行距1.65、中文1.75，按钮及导航500；英文首页步骤数字使用正体500。技术诊断代码仍使用等宽字体。标题约30—42px，功能标题13—17px，主要操作与确认文案11—13px，辅助注释更小。最终字号可依据审核和实际设备继续调整。

本轮参考[Apple字体说明](https://developer.apple.com/fonts/)与其官网SF Pro字体栈的字重和大小层级，实际选用[Inter官方字库](https://rsms.me/inter/)作为本站字体，并非使用或分发Apple字体。固定版本、下载来源、SHA-256和OFL许可位于frontend/public/assets/fonts/inter-4.1/；字体随站点同源加载，常规字体预加载，斜体按需加载，不请求字体CDN。

中文字体来自[Google Fonts官方字库](https://github.com/google/fonts/tree/main/ofl/notosanssc)，保留官方101个unicode-range分片，总计4,500,544字节，浏览器按页面文字加载所需分片；不一次预加载整个中文字库。原始URL、各文件SHA-256、固定提交许可来源见frontend/public/assets/fonts/noto-sans-sc-v41/manifest.json和OFL.txt；字体声明在src/vue/noto-sans-sc.css，随主CSS构建获取指纹缓存，所有字体请求同源。

桌面最大内容宽度1280px，上传栏310px，主区自适应，间距22px；面板18px圆角，内部画面10px圆角。手机改为单列，开始演示后滚动到试衣区，结束按钮固定在可触达位置。

| 顶部导航 | 创作空间、体验指南、受邀体验示意弹窗 |

倒计时和错误均由本地逻辑演示，不是账户、API 或网络实测。人台插画保持静态，上传服装不会改变人物或生成视频；标签和底部工具栏持续明确其示意性质。原型未实现真实相机选择、模型接入或运营后台。

当前不访问相机、不采集音频、不发送图片、不使用 localStorage；上传图片只在页面内处理与预览，替换/离开后释放相关引用。正式数据处理文案仍需根据最终供应商条款收敛。
