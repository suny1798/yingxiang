## 范围和次序

先按16附录A建立Pinia最小UI／身份世代协调与Vue Query服务器查询，再迁登录注册／退出、原账号菜单和本人页面。Pinia不保存媒体、参考图、令牌、草稿或服务器账号详情；Query仅内存，不加入持久化插件。私有key包含用户UUID和世代；退出／换账号先推进世代、取消并清除私有查询，迟到响应不得提交。写操作不自动重试，未知结果需核查。轮询只放公共容器，不为每页新增一份计时器。

首批实现可单独验证协调器与缓存合同并提交，不将未接UI或未真实旧后端联调写为M04完成。SDK／模型／Stripe均关闭，登录后不自动生成或购买。登录失败、本人读取失败、退出失败保留可恢复状态且不得把缓存视为成功。

旧FastAPI联调用随机回环端口、临时SQLite和合成账号；先核对配置／Alembic／原HTTP fixture工具，不复制正式用户、长期密钥、媒体或真实权益。复用现有后端依赖环境运行，不读写正式数据库。身份由服务器Cookie证明，客户端角色只控制呈现，直接访问仍须后端授权。

验证至少覆盖匿名→登录／注册→刷新→退出、跨账号私有列表不复用、401／403、进行中的旧请求忽略取消仍不能提交、同账号重新登录世代隔离、失败／离开清理以及价格确认登录衔接。实际浏览器通过隔离Nginx或Vite再接临时FastAPI；替身与真实旧后端证据分开。源码／类型／必要测试与构建通过后按功能本地commit，不push，不等待逐次指令。
