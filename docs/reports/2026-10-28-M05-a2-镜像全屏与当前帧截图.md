# M05-a2：画面镜像、全屏与当前帧截图

比较点e8c150a；关联FR02/03/27/29/47/48、T51-C06/C07与[M05-a任务卡](../migration/tasks/M05-a-Vue本机媒体与画面工具.md)。本片在a1本机预览上恢复镜像、全屏与主动PNG截图，不含云端换装、视频预览或录制。

## 实现

镜像、全屏与截图由页面级`LocalFrameTools`统一持有，Vue仅通过`useFrameTools`桥接快照，流、视频元素和导出结果仍归页面，不进入Pinia／Query或持久化存储。默认镜像开启，与旧`PreviewPanel`一致；镜像只改`data-mirrored`与后续截图像素，不重建视频元素、不重新申请相机。

截图复用既有`captureVideoFrame`／`downloadVideoFrame`：点击时固定当前镜像与视频元素，按源尺寸导出PNG，文件名为`映想-相机原画-<ISO时间>.png`，仅本机下载，不入作品、不上传、不调用模型。未就绪、绘制失败与空编码分别显示原错误；成功提示沿用“已导出当前画面，截图仅保存在你选择的位置。”。

全屏目标仍是`[data-preview-stage]`画框，沿用原`.preview-frame:fullscreen`样式；支持状态读取`document.fullscreenEnabled`，无相机时与截图一起禁用。`fullscreenchange`、`visibilitychange`、`pagehide`及账号变化监听在卸载时成对注销；卸载时若本画框仍全屏则退出。

取消语义：隐藏、`pagehide`、退出／换账号或卸载会推进操作号，迟到PNG既不下载也不通知，截图按钮恢复可用；换账号清理由`SessionScope`回调触发，不新开相机或重建预览。

图标几何抽为`lib/studio/icon-paths.ts`，与旧React`icon.tsx`逐项机械对照，Vue`StudioIcon`支持镜像、全屏／退出与截图图标；`MediaTools.vue`、`MirrorButton.vue`沿用原CSS模块与文案，未新增视觉方向。`CameraPreview.vue`仅暴露本页视频元素供截图读取。

## 实际验证

完整`npm run check`通过：OpenAPI类型、Vue类型、161项测试（原153项＋7项画面工具编排＋1项图标机械对照）、Vite构建。`legacy:typecheck`通过；`npm run smoke`通过16条静态路由与SDK非空检查。

Playwright CLI在1440×1000与1280×900桌面执行`scripts/browser/local-studio-tools-check.js`通过：相机未开时全屏／截图禁用；合成canvas红绿画面（左红右绿）下，默认镜像截图的PNG为640×360、`image/png`，左绿右红，关闭镜像后左红右绿，文件名与成功提示正确。镜像切换后视频元素与`getUserMedia`计数不变。

空帧（明确覆写`readyState=0`）与`toBlob`返回null均显示原错误、不产生下载且按钮恢复；延迟`toBlob`后切后台与站内离开，释放结果均无迟到下载。全屏进入后目标为当前画框、按钮变为“退出全屏”，退出后恢复；明确拒绝`requestFullscreen`时显示“暂时无法切换全屏…”且不进入全屏。英文／暗色下按钮与提示翻译正确，视频元素与`srcObject`保持。

a1桌面脚本回归重跑通过；因新增镜像按钮同样带`aria-pressed`与`title`，其服装缩略图选择器收窄为`main button[aria-pressed][title]:not([data-mirror-control])`，断言未放宽。

运行时异常0、MediaRecorder实例0、业务上传／模型／付款mutation 0，资源记录无SDK／LiveKit预热或生成API读取。相机为明确替换的canvas合成流，全屏与空帧为明确替身；不是实际摄像头硬件、系统全屏或真实生成效果实测。临时后端为临时SQLite旧FastAPI，结束后停止；正式数据库、媒体和原工作区未改。
