## 输入与行为切片

先复用src/components/site/works-page.tsx的列表、筛选、卡片与文案，以及works-page.module.css；API合同为GET /api/works（kind／page／pageSize／sort／q／favorite）和POST /api/works/{id}（收藏）。原页面同时包含详情、Range、参考图、提示词、下载、改名与删除，本片先交付可独立验收的列表闭环，详情与作品操作归M06-b。

列表状态必须包含：账号读取中、未登录、加载中、首次失败可重试、空列表、分类空态、筛选无结果、收藏中、分页边界，以及后台保存状态（capturing／waiting／saving／ready／failed）。私有请求经SessionScope捕获账号世代，退出／换账号取消旧请求、清空旧列表，迟到响应不得提交到新账号界面；轮询仅在页面可见时进行，离页停止。

本片不实现详情弹窗、视频播放／Range、参考图大图、提示词历史、镜像下载、PNG截图、改名、删除或重试保存；卡片不提供未实现的详情入口，避免把半成品当完成。不改变API、数据库、权益或正式作品。
