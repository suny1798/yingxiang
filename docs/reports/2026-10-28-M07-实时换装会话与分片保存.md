# M07：实时换装会话与分片保存

比较点2e3b27e；关联FR04—11／20／21／46、T51-C05—C07与[M07任务卡](../migration/tasks/M07-Vue实时换装闭环.md)。本片把Vue创作空间接到既有实时会话控制器，完成主动开始、首帧计时、同连接换衣、结束、录制与分片保存。

## 实现

`useTryOnSession`复用`SessionController`、`DecartTryOnAdapter`、`LocalCamera`、`CameraPreviewSession`与`RemotePreview`，只做Vue订阅桥接；SDK、令牌、远端流与观察仍由原控制器拥有。`useGarmentMedia`复用`GarmentInput`，把选图接到`controller.setGarment`；已认证身份变化清空素材，访客登录保留仍有效内容。

`PreviewPanel.vue`沿用原预览面板DOM／文案／CSS：相机原画／映想画面、云端确认、开始／结束、首帧后倒计时、同连接换衣、换装服务门禁、原画提示、镜像、全屏、当前帧PNG、回放与下载。`useGeneratedRecording`在远端实际播放后开始录制无声生成流，经`WorkUpload`分片保存并保存本轮参考图；停止、切后台、离开或换账号收尾，不重新生成。`CameraPreview`增加`visible`／`remote`以区分原画与AI画面，原有本机预览行为不变。

账号、相机、路由和页面隐藏的清理保持：访客登录不停止预览，已认证身份或角色变化停止会话；离开页面停止相机、远端流与录制。真实供应商开关、预算、账号白名单与费用授权不变。

## 实际验证

完整`npm run check`通过：OpenAPI类型、Vue类型、175项测试（既有会话控制器、SDK适配、录制、作品上传等全部回归）、Vite构建；`legacy:typecheck`通过；`npm run smoke`通过18条路由。SDK构建入口现在从共享实现chunk再导出，smoke改为解析该依赖并检查其非空，避免把SDK被摇树误报或漏报。

Playwright CLI在1440×1000桌面执行`scripts/browser/studio-session-check.js`通过。临时SQLite旧FastAPI、合成canvas相机、明确路由替换的SDK替身及合成status／token／observation响应：

- 注册新账号后打开相机、选择两张服装图、切到映想画面、确认云端处理后主动开始。
- 远端流延迟1.2秒提供，首帧播放后计时从00:15开始，连接等待未扣体验秒数。
- 同连接切换第二张服装图触发一次参考图更新，令牌请求仍为1次，倒计时不重置。
- 远端画面当前帧PNG为320×180，全屏目标为画框；结束后远端流停止、相机原画保留、observation只上报一次。
- 录制分片经真实作品接口保存，界面显示“已保存到我的作品”，回放可打开；离开页面后全部本机与远端轨道结束，浏览器异常0。

a1／a2／a3／作品列表四个桌面脚本在同一构建回归通过。a1／a2中原“无SDK预加载或生成接口读取”的M05断言已更新为“无token／observation／模型POST”，因为M07在创作页读取服务状态并预加载SDK属于预期行为；本机预览、截图、视频选片与作品列表行为未回退。

## 边界与未覆盖

- SDK、status、token、observation均为明确替身；没有真实供应商连接、真实签发、扣减或账单核对，生成画面来自合成canvas流。
- 分片保存使用真实临时作品接口，但媒体不是真实模型输出；真实效果、费用与供应商可用性未验。
- 隐藏／pagehide 的会话停止由既有控制器单测和本轮路由离开验证，未另做真实系统切后台硬件测试。
- 未切换正式入口、未push；临时后端、预览服务与浏览器已关闭，示例视频副本已删除。

Spec／Standards为同Agent自检，非独立Review。按M完成度本地提交，不push、不切流。M07完成；M08视频／实时编辑、M09入口与G1仍独立验收。
