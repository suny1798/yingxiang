# M15：实时作品保存闭环

父片M15，关联FR46／49、NFR06—08及T51-C07／10。依赖M12与M13隔离入口；Vue入口与正式切流未迁移。

按两片验收：

- **M15-a 分片与参考图原子保存**：`POST /api/works`仅接受realtime／edit、mp4／webm、15／30／60秒，owner必须等于本人且`X-Work-Owner`绑定；`POST /api/works/{id}/chunks/{index}`按0起连续、重复同内容幂等、不同内容409、乱序409、空片段400、总量≤32MB；`POST /api/works/{id}/references/{ref}`校验PNG／JPEG／WebP与像素上限、同ID同内容幂等、不同内容409、最多24张、仅capturing／waiting／saving可加。文件先写临时文件并fsync，再原子替换，随后数据库确认。
- **M15-b 详情、Range、搜索收藏与删除防复活**：详情只返回本人；ready才给contentUrl；`/content`支持单段Range（206／416）、inline／attachment；列表支持kind／q（≤60字符、无控制字符、转义LIKE）／favorite／sort（newest／oldest／title）／页码收敛；改名1—60字符；收藏不改updatedAt；删除仅允许非capturing／waiting／saving，清空标题与收藏、删除参考图行与文件；删除后分片／完成／参考图／详情／下载均404，列表排除。

实现：`StoragePort`＋`LocalPrivateStorage`（本机私有卷、UUID路径、拒绝符号链接、临时文件＋fsync＋原子移动）；`WorksService`＋`WorksController`。realtime／edit在complete请求内同步完成拼接与校验并转ready；视频作品保存队列留M17。Servlet multipart关闭不影响本片（分片与参考图为原始字节流）。

验收：随机临时schema＋独立临时存储目录；真实PG＋两Java进程（重启持久）；85项检查覆盖上述行为与空录像／部分保存／参考图失败提示、WebM、他人隔离、删除后文件与引用清理；54项JUnit（含存储路径／原子写）。M13／M14同批回归通过。

边界：本机单卷，不代表对象存储／多机；M17 Worker收取视频结果、M18合并删除与租约未做；提示词接口留M16；未改V1／正式库，未接Vue，未切换8787／8788。证据见[报告](../../reports/2026-10-29-M15-实时作品保存.md)。
