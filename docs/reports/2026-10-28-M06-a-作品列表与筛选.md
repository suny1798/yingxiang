# M06-a：作品列表与筛选

比较点e979b1d；关联FR46/49、T51-C03/C07与[M06-a任务卡](../migration/tasks/M06-a-Vue作品列表与筛选.md)。本片迁移“我的作品”列表：分类、搜索、排序、收藏、分页、轮询与账号隔离；详情、Range、参考图大图、提示词、下载、改名与删除留M06-b。

## 实现

`WorksIndex`持有筛选与列表状态，所有私有读取经`SessionScope`捕获账号世代：退出／换账号先取消在途请求、清空旧列表，迟到响应经世代检查丢弃；未登录不发私有请求。轮询只在页面可见时进行，另在窗口聚焦和站内`yingxiang:works-changed`事件时刷新，离页停止。

`WorksPage.vue`沿用原works-page.tsx的DOM／文案／CSS：分类工具条、搜索框、排序、仅看收藏、卡片（预览、分类、时长、保存状态、参考图缩略图与数量、收藏按钮）、分页、空态与页脚。账号读取中、未登录、首次加载失败可重试、分类空态、筛选无结果分别显示原状态；卡片暂不提供详情入口，避免把M06-b未完成的能力当作可用。

收藏走真实`POST /api/works/{id}`并携带`X-Work-Owner`，成功后更新当前卡片并静默刷新（取消收藏后“仅看收藏”会正确移除该项）；失败只通知并释放忙碌状态。请求参数固定`pageSize=9`、`kind/page/sort/q/favorite`，与旧页面一致。

## 实际验证

完整`npm run check`通过：OpenAPI类型、Vue类型、174项测试（a3的169项＋5项作品列表编排）、Vite构建；`legacy:typecheck`通过；`npm run smoke`通过18条静态路由（新增/works）与SDK非空检查。

Playwright CLI在1440×1000与1280×900桌面执行`scripts/browser/works-index-check.js`通过。临时SQLite旧FastAPI上注册合成账号，经真实合同创建13件作品（11件capturing、1件带参考图的ready实时换装并收藏、1件ready实时编辑；标题走真实改名接口），再新增1件并完成保存验证轮询：

- 未登录显示登录门禁；新账号显示“暂无作品”。
- 首屏9张卡片、总数13；“最新创建”按创建时间、“最早创建”与“按名称排序”按服务端顺序；搜索“夏夜”得到2件并可清除。
- 仅看收藏得到1件；取消收藏后收藏筛选正确变空；清除筛选恢复13件。
- 实时编辑分类得到1件并显示“提示词创作”；视频换装分类显示“这个分类暂无作品。”；分页2页、4件尾页及前后页禁用正确。
- 新增作品先显示“正在生成并保存”，完成后≤5秒轮询自动变为“已保存”，无需刷新。
- 首屏读取被拦截时显示“暂时无法读取作品”，解除后“重新加载”恢复14件。
- 退出并注册第二账号显示空列表；重新登录第一账号恢复14件，旧列表未串号。
- 英文／暗色下列表文案与收藏筛选翻译正确；1440×1000与1280×900无横向溢出。
- 列表切片无提示词或下载请求、无模型／视频／支付mutation；a1／a2／a3桌面脚本在同一构建上回归通过。

作品内容为仅含WebM文件头的合成字节，只用于列表卡片与状态，不证明可播放；详情播放、Range、参考图大图、提示词与下载将在M06-b用可解码合成媒体验证。临时后端结束后停止，正式数据库、媒体和原工作区未改。
