| 接口 | 当前返回 | 关键约束 |
| --- | --- | --- |
| GET /api/v1/config | 200，模式、场景、时限、图片限制、未启用功能 | no-store；只返回白名单字段，不返回环境变量或凭据 |
| GET /api/v1/health | 200，应用健康、mode=real、providerReady=false、storageReady=false | 不探测或创建付费模型会话；不把应用健康等同模型可用 |
| POST /api/v1/access/redeem | 503 SERVICE_DISABLED | 不设置登录Cookie |
| POST /api/v1/sessions | 503 SERVICE_DISABLED | 不创建虚假业务会话或预留 |
| POST /api/v1/sessions/{id}/token | 503 SERVICE_DISABLED | 不读取长期密钥、不访问供应商、不返回假令牌 |
| POST /api/v1/sessions/{id}/heartbeat | 503 SERVICE_DISABLED | 不声称已持久化心跳 |
| POST /api/v1/sessions/{id}/end | 503 SERVICE_DISABLED | 不声称已停止供应商连接 |

所有 JSON 响应包含 no-store 和 nosniff。2026-10-29起统一响应为 `code`／`data`／`message`，并附 `requestId`；错误另带 `reason` 保留细分业务原因。成功时 `code=0` 且 `data` 为原业务对象；失败时 `code` 使用通用错误码（40000参数、40100未登录、40300禁止、40400不存在、40900冲突、41300过大、41500格式、50000系统、50300不可用），`data=null`，`reason` 如 `INVALID_REQUEST`、`NOT_FOUND`。二进制内容（作品视频、参考图、下载与视频准备结果）不包装。当前关闭错误不支持自动重试。

config中的mode=real表示主页默认真实模式，maxDurationSec=60、defaultDurationSec=15、durationOptions=[15,30,60]；features.realtime根据本机开关和服务端密钥是否配置返回布尔值，不表示已建立连接。features.camera=true不表示相机正在采集或全部设备通过。健康接口providerReady=false、storageReady=false，不探测供应商或数据库。真实告知版本2026-10-23-preview-cloud-v2。

## 5. 真实接口的实现契约

以下为后续DEV04的输入输出与约束，当前未启用。所有时间使用UTC ISO 8601，数据库时间为 timestamptz；每日额度以服务端 Asia/Shanghai 自然日为初始设计，变更时重新核对业务需求。

| 接口 | 请求字段与验证 | 成功响应 |
| --- | --- | --- |
| access/redeem | code：去首尾空格后8—64个ASCII字母或数字；不接受额外字段 | 200，accessExpiresAt、remainingQuota；设置受保护的随机业务Cookie |
| sessions | consentVersion：必须与 config 一致；Idempotency-Key：16—128个ASCII字母、数字、连字符或下划线 | 201，sessionId、deadlineAt、maxDurationSec、remainingQuota |
| {id}/token | 路径UUID；body.connectionAttemptId：UUID；不允许客户端指定模型、价格或时限 | 200，apiKey、expiresAt、maxSessionDurationSec |
| {id}/heartbeat | 路径UUID；seq：非负安全整数；playbackState：connecting/live/reconnecting；errorCode：允许的脱敏枚举，可省略 | 200，accepted、deadlineAt；截止时间不延长 |
| {id}/end | 路径UUID；reason：user/timeout/hidden/error/pagehide；seq：非负安全整数 | 200，endedAt；重复结束返回首次结束时间 |

请求体最大4KB，仅接受application/json；解码错误、额外字段或错误类型返回400。Cookie通过HttpOnly、Secure、SameSite=Lax管理，生产仅HTTPS；开发localhost环境单独配置。所有变更接口校验规范化Origin和会话CSRF令牌，不把CORS当作鉴权。

业务会话必须属于当前身份。不存在和其他身份的会话统一404，不泄露归属；邀请管理与停发开关使用独立受保护入口。服务停用时优先拒绝签发，仍不承诺已有直连立即停止。

### 幂等和重试

- 会话幂等键以 `(visitorId, operation, idempotencyKey)` 唯一；保存规范化请求摘要、状态及原响应，保留24小时。相同键和请求返回原响应，键相同而请求不同返回409；并发相同请求只能一次预留。
- 令牌尝试以 `(sessionId, connectionAttemptId)` 唯一。只在令牌有效期内用受保护的短期缓存重放同一响应，数据库不保存令牌正文；已过期或签发结果不确定的尝试不隐式签发第二枚，分别返回409或503，并保留风险记录。
- 上游超时视为可能已签发，不立即释放费用预留；用户重试需要新的明确尝试号，并受总次数/频率和风险预算限制。
- 心跳seq只接受递增新事件；旧序号返回accepted=false且不改变截止时间。end先完成本地资源清理，再尽力上报；上报不成功由服务端过期回收兜底。

### 稳定错误映射

| HTTP | code | retryable及恢复 |
| --- | --- | --- |
| 400 | INVALID_REQUEST / CONSENT_VERSION_MISMATCH | false；修正输入或重新阅读说明 |
| 401 | UNAUTHORIZED | false；重新获取受邀身份 |
| 404 | SESSION_NOT_FOUND | false；不区分不存在与无权访问 |
| 409 | IDEMPOTENCY_CONFLICT / SESSION_EXPIRED / TOKEN_ATTEMPT_EXPIRED | false；禁止重放过期操作 |
| 429 | QUOTA_EXHAUSTED / CAPACITY_FULL / RATE_LIMITED | 额度耗尽为false；容量/频率为true并带Retry-After |
| 503 | SERVICE_DISABLED / UPSTREAM_UNAVAILABLE / TOKEN_RESULT_UNKNOWN | 默认false；明确用户恢复路径，禁止前端无限重建会话 |

错误message为可读中文，日志使用稳定code和requestId；不记录请求中的邀请码、令牌、媒体或完整上游异常对象。

## 6. 数据约束与一致性

数据库实体沿用主文档第11章，并在实施迁移前满足：

- AccessGrant.codeHash唯一；兑换与Visitor创建同一数据库事务，一次性邀请用条件更新防止并行兑换。
- TryOnSession.visitorId外键，状态限定reserved/active/ended/expired/abandoned，deadlineAt创建后不可延长；active仍不是可信计费证据。
- QuotaReservation.sessionId唯一；新增每日QuotaBucket，`(visitorId, quotaDate)`唯一，行级锁或条件更新实现预留，禁止先读后写的非原子扣减。
- TokenIssue中`(sessionId, connectionAttemptId)`唯一，不保存令牌正文；保留签发时间、过期、连接上限、未知结果和可能终止上界。
- UsageEvent.eventId唯一，按sessionId、occurredAt建索引；客户端时长仅作观测，不作最终账单。
- 金额使用整数微美元或精确小数；预估、风险预留、已确认费用独立记录。可能复用连接的风险不能按单个60秒窗口忽略。
- PostgreSQL是额度与会话事实来源；Redis只做短租约、限流及有效期内的受保护响应缓存。Redis预占成功但数据库失败时补偿释放；数据库成功但后续步骤失败时保留可对账状态并修复，不假设跨存储事务。
- 租约失效只释放业务容量，费用预留等到令牌可能连接终止上界和账单对账后再处理；删除/匿名化定时任务须覆盖对应索引与幂等重试。

实际SQL迁移、数据库/Redis故障注入、邀请码哈希方案及真实供应商计费对账在DEV04/POC中执行，本阶段不声称完成。

## 7. 本地状态与资源

会话控制器检查有效参考图和云端处理确认后才可开始；双击开启只创建一个任务，结束中止在途操作。换图串行提交，尚未处理的选择合并为最新项，连接中选图会在连接完成后应用。

换图不延长截止时间；后台、离开、取消确认或移除图片均结束体验。迟到连接不能复活会话。上传URL归图片输入Hook管理，替换、移除及卸载时释放，解码位图始终关闭。

图片在解码前检查大小、签名和PNG/JPEG/WebP尺寸，并拒绝APNG/动态WebP；解码后再次检查像素，最长边缩至1024且不放大，再重编码为PNG去除原图元数据。JPEG包含基线与渐进尺寸检查，WebP包含VP8、VP8L与VP8X。浏览器实际解码仍可能受实现和设备资源影响，不将头部检查视为完整解码器隔离；公开上传服务仍需服务端独立校验。浏览器与逻辑检查记录见[图片与相机验收](reports/2026-10-22-图片与相机验收.md)，完整FR验收尚未完成。

LocalCamera只采集视频并等待实际播放，DecartTryOnAdapter管理短期令牌、SDK连接及远端流。视频、图片和流不放入JSON、日志或存储。实时换装的相机原画与生成画面默认同向镜像，相机开关左侧的镜像按钮同步切换两路显示；仅修改播放器CSS，不改变模型输入、重连或续时；停止时结束轨道、卸载video并清空srcObject。页面、指南和隐私说明均对应实际云端路径。

## 9. 独立本机PoC接口（历史，现已移除）

| 接口 | 行为 | 输入/边界 |
| --- | --- | --- |
| GET /api/poc/status | 读取本地配置布尔值、批次状态、公开策略及本地访问凭据 | 不访问供应商；凭据不写报告/日志 |

记录在frontend/.cache/poc，受Git忽略。签发前reserved、成功issued、不能确认unknown；客户端上报可将issued记为finished，含义是尝试结束而非模型成功。上游超时或失败不释放次数，禁止自动删除或重置。记录不保存任何密钥、令牌或媒体。

浏览器直接将图片与相机视频发送至Decart，说明版本2026-10-23-cloud-poc-v1；只采集视频，SDK telemetry=false、noopLogger，完整诊断对象不输出。实际远端playing才进入live；停止关闭本地轨道、清空播放器并尽力上报，SDK迟到返回立即断开。SDK在途请求不能通过AbortSignal直接取消，故不承诺立即停费。页面SDK准备检查不签发令牌或建立供应商连接。

## 10. 主页面的本机开发接入

用户于2026-10-23明确要求不限手动次数，并将账号与完整后端留到下一步。主页使用DecartTryOnAdapter、固定SDK/模型和完整prompt+image更新，使用/api/studio/status、token、observation及YINGXIANG_STUDIO_ENABLED开关；策略由STUDIO_POLICY集中管理，门禁为StudioGate。状态查询GET /api/studio/status；POST /api/studio/token接收attemptId及consentVersion；POST /api/studio/observation接收归属该操作的有限观测。变更请求验证本机Host/Origin、X-Studio-Access随机凭据、JSON与4KB上限，响应no-store/nosniff。云端告知使用STUDIO_POLICY版本。

状态查询和SDK准备不签发。每次手动开启产生新UUID，使用frontend/.cache/studio/{attemptId}.json独占占位，同一UUID的并行/重放/重启后重放均拒绝，新的UUID不受总次数限制。记录模型、时限、状态和有限客户端观测，不保存密钥、令牌或媒体。与.cache/poc完全分开，不删除旧批次或访问凭据。令牌10秒TTL、固定模型/Origin、单连接15秒；客户端connecting开始后的总窗口最多15秒，包含签发与连接，看到画面的时长可能更短。

可在同一次连接中发送新服装图，不重新建连；结束、切后台、离开、取消说明、移除图片时关闭媒体，不自动恢复。新手动开启重新申请令牌，SDK provider拒绝一次操作内的再次拨号。旧/api/v1身份、会话及配额接口仍503，主页面不冒充已完成这些能力。
