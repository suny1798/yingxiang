# 映想

**让想象，在眼前发生。**

映想提供实时换装、视频换装和提示词实时编辑，三种创作的生成视频默认保存到“我的作品”。三个创作画面及作品详情另提供桌面全屏与当前帧 PNG 截图；截图仅本机主动导出，不上传、不自动入作品。我的作品支持标题搜索、最新/最早/名称排序及账号级收藏筛选。实时编辑已接入云端生成，支持在同一连接内添加、移除并同步完整提示词组合；用户于2026-10-26确认功能已实现，产品文案不再标为“仅交互预览”或“待接入”。当前仅测试账号suny开放视频与实时编辑，视频按原US$5/20次累计上限控制；suny的实时编辑按用户明确要求取消次数、累计预算及申请冷却限制。此状态不扩大其他账号权限，也不把首页概念图当作真实生成结果。视频换装此前的单次真实生成记录见[报告](docs/reports/2026-10-24-视频换装单次真实测试.md)。

实时编辑新作品同时保存本轮已同步的用户提示词组合，可在视频右侧“本次提示词”按序回看；未发送草稿不保存，旧作品没有留存的提示词不能补回。记录与视频同属私有用户作品目录，删除作品时一并清除。提示词只在本人详情接口读取，不写日志；该提示词记录不进行数据库迁移。

当前架构已迁为 **Next.js/React 前端 + FastAPI 独立后端 + SQLite**。浏览器仍访问同源 `/api/*`；Next.js 只转发请求，账号、订单、权益、预算和长期密钥统一由后端管理。迁移与实际验证见 [迁移验收报告](docs/reports/2026-10-24-FastAPI与SQLite架构迁移.md)。

**后续重构方向（2026-10-27）**：用户已确认前端采用 **Vue 3＋Vite＋TypeScript**，正式工程继续维护在 `frontend/`；后端采用 Java／Spring Boot 模块化单体与独立 Java Worker，优先核查已有云 PostgreSQL 作为单一主库，并接入已有 Redis。选型背景见[业务扩展与工程架构选型](docs/15-业务扩展与工程架构选型.md)，后续迁移统一按[前后端技术与架构迁移执行方案](docs/16-前后端技术与架构迁移执行方案.md)推进，实际工作包状态见[开发任务与验收](docs/05-开发任务与验收.md)。这是后续目标与执行方案，当前源码、服务与下方启动命令仍对应 Next.js／FastAPI／SQLite；尚未切换云库或新增业务。PostgreSQL实例不满足条件时先记录选型变更，再调整方言与测试，不同时使用两套业务主库。

已新增 [Java离线启动底座M10-a](docs/reports/2026-10-27-M10-a-Java启动底座.md)：工程位于原 `backend/`，Spring Boot4.1.2／JDK21／Maven Wrapper3.9.11，单独使用回环8792。它仅验证启动与HTTP边界，业务接口保持关闭，未切换当前应用；运行方式见[后端说明](backend/README.md)。Java已按picture现成工程接入JDBC／Redis Starter，默认local，接口统一 `/api`；PG（数据库名／用户名yingxiang）登录与只读查询、Redis认证／PING均通过；迁移schema尚未创建，见[配置修正记录](docs/reports/2026-10-27-M10-c-参考现成Java配置修正.md)。

## 本机启动

本机已安装隔离的 Python 3.13.17，SQLite 3.50.4；采用 DELETE/FULL，外键开启。前端仍使用 Node.js 22+。详细安装、备份与恢复命令见 [后端运行手册](backend/README.md)。

终端一：

```powershell
cd backend
.venv/Scripts/python.exe -m uvicorn app.main:create_app --factory --host 127.0.0.1 --port 8788 --workers 1 --no-access-log --no-proxy-headers --log-level warning
```

终端二：

```powershell
cd frontend
npm ci
npm run dev
# 或 npm run build 后 npm start
```

访问 [映想首页](http://127.0.0.1:8787/)。本机服务若已运行，不要再启动第二份。Python 命令在 backend/，npm 命令在 frontend/ 执行；根目录不使用 npm workspace。后端仅监听回环，不公开发布。

全新环境先按后端手册创建 venv、按哈希锁文件安装依赖、复制无密钥配置并显式执行 Alembic 初始化。**已有 data/ 数据库不要重复初始化、删库或重新发放额度。** 默认维护模式会拒绝业务写入；数据库不存在或版本不符不会静默创建空库。

## 目录与配置

```text
frontend/          页面、浏览器媒体/SDK、同源转发、npm锁文件、前端测试
backend/           FastAPI业务API、SQLite仓储、Alembic、依赖哈希锁及运维脚本
backend/data/      私有数据库与迁移快照（忽略，不提交）
docs/api/          导出的OpenAPI合同
prototypes/ui-v1/  静态视觉设计参考
```

- `frontend/.env.local` 仅保留页面/Node配置与 `YINGXIANG_API_ORIGIN=http://127.0.0.1:8788`。
- `backend/.env` 保存模型/Stripe密钥、场景开关、预算、来源白名单、维护及数据路径。长期密钥不得放入 `NEXT_PUBLIC_*`。
- 当前数据库为 `backend/data/yingxiang.sqlite3`，账号含加盐 scrypt 摘要及会话摘要，不保存明文密码/会话Cookie。Cookie 名称、7天有效期、旧密码与有效会话语义保留。
- 原 `frontend/.cache` 已封存为历史，不再参与业务读写。停止通过修改其中 quotas/durationQuotas 维护权益；管理员可通过 `/admin` 调整实时换装可用次数，由短事务更新 grant 与唯一流水，并记录原因和审计。
- 数据库和备份未做静态加密，应按敏感资料保护。备份为显式运维命令，尚无自动备份调度及已验证的生产容量/RPO/RTO。

## 页面与实际行为

| 页面 | 用途 |
| --- | --- |
| / | 三场景介绍、原创概念插画轮播与创作入口（实时编辑为受控测试入口） |
| /pricing | 15/30/60秒 × 1/5/10次拟定价格；正式购买关闭 |
| /studio | 本机相机预览、多图衣橱、实时换装、全屏及当前帧截图 |
| /studio/video | 本地视频预览、本人任务与后台自动保存、全屏及当前帧截图；本机按获批预算开放 |
| /works | 本人生成视频及多张服装参考图，支持搜索、排序、收藏、分类、回放、下载、重命名与删除 |
| /studio/edit | 提示词组合实时生成、原画对比、镜像、全屏/截图及作品自动保存；仅指定测试账号可主动开始 |
| /account | 本人权益、最近使用、沙盒订单与账号资料 |
| /admin | 仅管理员：用户/权益、任务/订单查询、服务暂停、公告及审计；默认普通用户，无自动用户名提权 |

访客可先选图和打开本机相机；相机预览不上传、不占次数。只有主动确认云端处理并开始换装才检查登录、权益及供应商门禁。登录后不会自动生成。衣橱最多6张，每张≤10MB；同连接点选换衣不重签、不另占次数、不续时，刷新不保留图片。

普通新账号仍送一次15秒；30/60秒必须有该档服务端权益。结束/超时回收云端及克隆输入流，原相机可继续预览；关闭相机、切后台、离开或换账号清理全部媒体，不自动重连。无效请求不扣次数，上游结果未知则保留风险占用，不能删记录解锁。

视频接收1—15秒、≤25MB的H.264普通MP4；含音轨时自动在本站内存中拆轨后预览/生成，参考图≤10MB；输入人物视频仅在内存校验/转发；生成结果与本次使用的服装参考图默认保存至本人作品私有目录。任务元数据、预算预留和unknown持久保存，失败/到期不自动返还。提示词场景固定Lucy2.5、15秒、每次$0.30保守预留，已有1次issued及原预留完整保留。两个场景真实测试需另批预算，迁移未扩大授权。

Stripe 仅保留原沙盒门禁，正式购买恒关闭。沙盒订单与权益单独归类，不能增加真实AI次数；通知验签后查单，同事务去重发放。账号当前仍是本机用户名密码，不支持手机号验证或找回密码。退款/争议、商户资格和公开上线尚未完成。
